---
title: An average describes nobody
version: 1
---

Lantern's customers have spent R$ 1,046,756.40 between them, which is R$ 395 each. No customer behaves
like that average. Some ordered once in a promotion and never came back; some order every few weeks and
account for a third of the revenue. A number for "the customer" blends groups that need opposite things,
and the action it suggests fits none of them.

The three tools in this lesson split the average in three different directions:

| tool | splits customers by | answers |
|---|---|---|
| a **segment** | what they are or do now | who should get this call, this offer, this e-mail? |
| a **cohort** | when they started | are the customers we get now better or worse than the ones we got before? |
| a **funnel** | how far they got on a path | where do people give up on the way to a purchase? |

Each has a classic mistake, and each mistake produces a number that looks correct. For segments it is a
rule that splits identical customers; for cohorts, counting months that have not happened yet as months
in which nobody came back; for funnels, a step whose definition quietly changed. This lesson makes each
mistake on Lantern's data first and then fixes it, because a mistake you have made once is one you
recognise.

**A segment earns its place by changing an action.** If the offer, the call or the message would be the
same for two groups, splitting them is decoration. Before building one, write down what will be done
differently for each part — the same test lesson 7 applied before sending a field to the CRM.
