---
title: Uma média não descreve ninguém
version: 1
---

Os clientes da Lantern gastaram R$ 1.046.756,40 no total, o que dá R$ 395 cada. Nenhum cliente se
comporta como essa média. Alguns compraram uma vez numa promoção e nunca voltaram; alguns compram a cada
poucas semanas e respondem por um terço da receita. Um número para "o cliente" mistura grupos que
precisam de coisas opostas, e a ação que ele sugere não serve a nenhum deles.

As três ferramentas desta aula partem a média em três direções diferentes:

| ferramenta | divide os clientes por | responde |
|---|---|---|
| um **segmento** | o que são ou fazem agora | quem deve receber esta ligação, esta oferta, este e-mail? |
| uma **coorte** | quando começaram | os clientes que conquistamos agora são melhores ou piores que os de antes? |
| um **funil** | até onde chegaram num caminho | onde as pessoas desistem no caminho até uma compra? |

Cada uma tem um erro clássico, e cada erro produz um número que parece certo. Para segmentos, é uma regra
que separa clientes idênticos; para coortes, contar meses que ainda não aconteceram como meses em que
ninguém voltou; para funis, uma etapa cuja definição mudou em silêncio. Esta aula comete cada erro primeiro
nos dados da Lantern e depois o corrige, porque um erro que você já cometeu uma vez é um erro que você
reconhece.

**Um segmento merece existir quando muda uma ação.** Se a oferta, a ligação ou a mensagem seria a mesma
para dois grupos, separá-los é decoração. Antes de montar um, escreva o que vai ser feito de diferente para
cada parte — o mesmo teste que a aula 7 aplicou antes de mandar um campo ao CRM.
