usually the person least able to spot a mistake. Review it first. Here is a page of the kind this

The left-hand page has no wrong number on it and five reasons to be misread. The right-hand page has
the same data. What changed is a checklist, which fits on a card:

| check | the question to ask of every number on the page |
|---|---|
| question | which of the reader's questions does it answer? If none, remove it |
| context | what is it compared with, and is that the comparison the question needs? |
| period | is the period complete? If not, is it compared with the same part of the last one? |
| size | is it a rate on a handful of events? Then show the count beside it |
| freshness | does the page say when its data ends? |
| filters | what is filtered, and does every card answer to the same filters? |
| definition | can the reader reach the definition of each measure from the page? |
| colour | does any colour carry meaning alone, without a word or a number? |

Eight checks, every number. It takes ten minutes on a finished page, and it finds something every
time. The two that find the most are period and context, which is why this lesson spent the most time
on them.
