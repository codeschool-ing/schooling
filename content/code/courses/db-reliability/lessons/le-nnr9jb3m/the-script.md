---
title: The rehearsal as a script
version: 1
---

A rehearsal done by hand is done slightly differently every time, and its numbers cannot be compared.
Written down as a script, it checks the same things in the same order and reports the same numbers,
and **the person running it can watch instead of type**. Save this as `rehearsal.sh` in your home
directory, beside lesson 19's `orders.sh`, and make it executable:

```schooling-example
{"language": "sh", "file": "rehearsal.sh", "parts": [{"code": "#!/bin/sh\n# rehearsal.sh: kill the Patroni leader on purpose, while orders.sh runs,\n# and report what the shop saw. A replica's lag that is not a number (`unknown`, for a stopped node) counts as 999, so that it can only stop the rehearsal."}, {"code": "if [ $# -ne 4 ]; then\n  echo \"ABORT: could not read the cluster's state\"\n  exit 1\nfi\nif [ \"$1\" != 3 ] || [ \"$2\" != 3 ] || [ \"$3\" != 0 ] || [ \"$4\" = none ]; then\n  echo \"ABORT: $1 members, $2 healthy, lag $3 MB, leader $4\"\n  exit 1\nfi\nleader=$4", "note": "The abort criteria, checked before anything is touched. A rehearsal on a cluster that is already degraded is not a rehearsal: it is the incident. Anything the script cannot read, including a Python error that printed nothing, is a reason to stop, and the comparisons are of text so that a word where a number belongs fails them rather than slipping past."}, {"code": "before=$(psql -h 127.0.0.1 -p 5000 -U postgres -XAt shop -c \"SELECT count(*) FROM orders\")\necho \"$(date +%T) healthy: 3 members, leader $leader, lag 0\"\n\n./orders.sh > rehearsal.log 2>&1 &\nsleep 5", "note": "The number to compare at the end: how many orders the table holds before the shop starts."}, {"code": "echo \"$(date +%T) killing $leader\"\npkill -9 -f \"patroni/$leader[.]yml\"\nkill -9 $(head -n 1 ~/patroni/$leader/postmaster.pid)\nwait", "note": "The failure: the leader's Patroni and PostgreSQL, killed as a dead machine would be."}, {"code": "after=$(psql -h 127.0.0.1 -p 5000 -U postgres -XAt shop -c \"SELECT count(*) FROM orders\")\necho \"orders ok: $(grep -c ok rehearsal.log), failed: $(grep -c FAILED rehearsal.log)\"\necho \"first failure: $(grep -m 1 FAILED rehearsal.log | cut -c1-8)\"\necho \"back at: $(grep -A 1 FAILED rehearsal.log | tail -n 1)\"\necho \"new rows in the table: $((after - before))\"", "note": "The report: what the customers saw, and whether the table agrees with them."}, {"code": "patroni ~/patroni/$leader.yml > ~/patroni/$leader.log 2>&1 &\nsleep 30\npatronictl -c $cfg list", "note": "The way back: the killed node is started again and rejoins as a replica, and the last line shows the cluster whole."}]}
```
