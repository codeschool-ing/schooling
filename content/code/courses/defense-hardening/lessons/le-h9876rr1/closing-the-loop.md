**This lesson comes near the end of the course, and it is the one the others rest on.** Lesson 1 said
so in its first section: you cannot remove what you have not listed. Read back through the course
with the inventory in mind, and each lesson turns out to consume one of its columns:

| lesson | the control | what it needs from the inventory |
|---|---|---|
| 1 | removing services, accounts and features | the machine's role, to know what its job needs |
| 2, 3 | benchmarks and centralised configuration | the list of machines to apply to, grouped by role |
| 4, 5 | network and port access control | which devices are allowed, and their hardware addresses |
| 7 to 12 | antivirus, EDR, DLP, host firewall, HIPS, sandboxing | which machines have each control, and which do not |
| 13, 14 | honeypots and sinkholes | which addresses are legitimate, so that a touch means something |
| 15 | the jump server | which machines are servers, and who administers them |
| 16 | vulnerability management | the installed software, and how exposed and critical each machine is |
| 17 | patching | the rings, and proof that every machine took the update |

Two of those deserve a second look. **Lesson 13's honeypot works only because of the inventory**: a
touch on `trap` is a finding because nothing legitimate should go there, and you can only say that
about a machine everybody knows is bait. Here it showed up as an unlisted machine, which is the
correct state for a decoy as long as somebody does know: the honeypot's own row belongs in a
restricted part of the records, not in none of them. And **lesson 17's last question**, whether the
laptop that was switched off for a month took the update, has no answer anywhere except in a collection
like the one this lesson ran.

## The order of work, if you start from nothing

A firm with no inventory today should not start with the controls of lessons 7 to 12. It should start
here: list the machines, measure them, find the ones nobody owns, give every one an owner and a role.
Then lesson 1 on each, then lesson 16's cycle on all of them. **The controls are only as complete as
the list they are applied to**, and the list is the cheapest thing in this course to build.
