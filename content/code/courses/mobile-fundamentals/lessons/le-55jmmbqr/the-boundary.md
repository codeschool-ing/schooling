**Nothing in this course needs a phone, a Mac or the Android SDK.** Every program you run here is
TypeScript on Node.js, on the computer you already have. That is deliberate: the rules of lessons 4
to 20 are the same on both platforms, and a small program that models one of them shows the rule
without a toolkit in the way.

**Where a lesson shows platform code, it shows three side by side**: Kotlin with Jetpack Compose,
Swift with SwiftUI, and React Native. Those fragments are short, they are quoted from each
platform's own documentation, and **they were not compiled or run for this course**. Each lesson
that shows one says so beside it. You read them to recognise the same idea in three spellings; you
will write them in the course you choose at the fork.

## The courses after this one need more, and here is what

The track forks after this course, and you take one of three routes. This is what each needs on your
computer, so that nobody discovers it in the middle of a lesson:

| course | what it needs beyond Node.js and git |
|---|---|
| `kotlin` | a Java Development Kit, version 21, and Gradle through its wrapper; any computer |
| `android-apps` | the above, plus Android Studio and its SDK, and an emulator or an Android phone with a cable |
| `swift` | the Swift 6 toolchain, which installs on Linux and macOS |
| `ios-apps` | **a Mac with Xcode** for everything that draws a screen; the plain Swift runs on Linux |
| `javascript`, `react-native` | Node.js 22, which you install today, and Expo; a phone with Expo Go, or the browser |
| `mobile-delivery` | an account with each store you publish to, and **both stores charge for one** |

**The iOS route is the only one that needs a particular computer.** Apple's Xcode runs on macOS
alone, and so does the simulator. Without a Mac, the `ios-apps` course is one you read more than
you practise; its own first lesson says where the line falls. The Android route runs on any
computer that can run Android Studio, and the React Native route on any computer that runs Node.js.

**The stores' fees are the other thing worth knowing before you choose.** Lesson 20 says what each
one charges and what for, with the date the figure was read. Nothing in this course asks you to pay
for anything.
