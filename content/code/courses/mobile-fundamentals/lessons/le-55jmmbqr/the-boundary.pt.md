**Nada neste curso exige um celular, um Mac ou o SDK do Android.** Todo programa que você roda aqui é
TypeScript no Node.js, no computador que você já tem. Isso é proposital: as regras das aulas 4 a 20
são as mesmas nas duas plataformas, e um programa pequeno que modela uma delas mostra a regra sem um
kit atrapalhando.

**Quando uma aula mostra código de plataforma, ela mostra três lado a lado**: Kotlin com Jetpack
Compose, Swift com SwiftUI e React Native. Esses trechos são curtos, foram tirados da documentação de
cada plataforma e **não foram compilados nem executados para este curso**. Cada aula que mostra um
deles diz isso ao lado. Você os lê para reconhecer a mesma ideia escrita de três jeitos; vai
escrevê-los no curso que escolher na bifurcação.

## Os cursos depois deste precisam de mais, e é isto

A trilha se divide depois deste curso, e você segue uma de três rotas. Isto é o que cada uma precisa
no seu computador, para ninguém descobrir no meio de uma aula:

| curso | o que precisa além de Node.js e git |
|---|---|
| `kotlin` | um Java Development Kit, versão 21, e o Gradle pelo seu wrapper; qualquer computador |
| `android-apps` | o de cima, mais o Android Studio e o SDK dele, e um emulador ou um celular Android com cabo |
| `swift` | o toolchain do Swift 6, que instala em Linux e macOS |
| `ios-apps` | **um Mac com Xcode** para tudo o que desenha uma tela; o Swift puro roda no Linux |
| `javascript`, `react-native` | o Node.js 22, que você instala hoje, e o Expo; um celular com o Expo Go, ou o navegador |
| `mobile-delivery` | uma conta em cada loja onde você publicar, e **as duas lojas cobram por uma** |

**A rota do iOS é a única que exige um computador específico.** O Xcode da Apple roda só no macOS, e
o simulador também. Sem um Mac, o `ios-apps` é um curso que você mais lê do que pratica; a primeira
aula dele diz onde fica a linha. A rota do Android roda em qualquer computador que rode o Android
Studio, e a do React Native em qualquer computador que rode Node.js.

**As taxas das lojas são a outra coisa que vale saber antes de escolher.** A aula 20 diz quanto cada
uma cobra e pelo quê, com a data em que o valor foi lido. Nada neste curso pede que você pague por
coisa alguma.
