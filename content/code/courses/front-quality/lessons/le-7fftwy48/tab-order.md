They stop being the same when CSS moves something. A flex container with `flex-direction: row-reverse`,
an item given `order: -1`, a grid placing items by area, an element with `position: absolute` drawn in a
corner: each changes where an element is seen and none changes where Tab takes the focus, so the focus
jumps across the page in an order nobody would read in. That fails 2.4.3 *Focus Order*, and usually 1.3.2
*Meaningful Sequence* as well, which asks the same of a screen reader's reading order. **The fix is to put
the elements in the HTML in the order they mean**, and to lay them out from there.

## `tabindex`, and its three kinds of value

| value | what it does | when to use it |
|---|---|---|
| absent | the element's own nature decides: a button takes the focus, a `div` does not | almost always |
| `0` | puts an element that would not take the focus into the tab order, at its place in the document | a custom control, and only when no element exists for the job |
| `-1` | lets a script focus the element, and leaves it out of the tab order | where the focus is sent: the session row, the heading |
| `1` or more | puts the element **before** everything else, in order of the number | never |

**A positive `tabindex` is never the answer.** It does not move one element; it creates a second tab
order that runs before the first, and every element added to the page afterwards joins the first one,
after all the numbered ones. A page with one `tabindex="1"` sends the focus to that element first,
wherever it is, and then back to the top.

## Skipping what repeats

A page whose content sits behind a long menu makes a keyboard user press Tab through the menu on every
visit. 2.4.1 *Bypass Blocks*, level A, asks for a way past it, and the usual one is a **skip link**: the
first link of the page, hidden until it takes the focus, which jumps to the main content. The platform
this course runs on has one; press Tab once on any of its pages and it appears. The planner has one link
before its content and does not need one. Lesson 12 adds the landmarks that let a screen reader user jump
the same way.
