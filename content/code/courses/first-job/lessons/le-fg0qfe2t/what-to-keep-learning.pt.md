**Ferramentas** mudam a cada poucos anos: o sistema de chamados, o produto de monitoramento, o framework.
Aprenda **quando o trabalho pedir**, e não gaste suas noites correndo atrás de cada uma nova; o trabalho
ensina as que usa mais rápido do que um curso.

**A habilidade vizinha** é o que está ao lado do que você faz: scripts para quem está no suporte, redes para
quem desenvolve, SQL para quase todo mundo. **Uma de cada vez, escolhida de propósito**, é o que leva você do
júnior ao próximo degrau, porque deixa você terminar uma parte maior sem ajuda.

**Fundamentos** (como redes, sistemas operacionais, dados e software realmente se comportam, e como falham)
mudam devagar e se acumulam. A trilha ensinou sobretudo esta camada, e é por isso que vai durar mais que as
ferramentas com que foi ensinada. Depois da trilha, **esta é a camada que ninguém agenda para você**: o
trabalho raramente pede que você entenda por que algo funciona, só que faça funcionar.

**Certificações** têm seu lugar, sobretudo em suporte e infraestrutura, em que alguns empregadores filtram
por elas. Faça uma quando um anúncio que você quer pedir, ou quando ela dá estrutura à habilidade vizinha; não
como substituta do trabalho.
