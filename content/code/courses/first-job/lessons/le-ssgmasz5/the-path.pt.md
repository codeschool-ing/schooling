**A página do perfil** tem de dizer, nas poucas linhas acima dos repositórios, **quem você é e o que você
faz**: seu nome de verdade, uma linha (a mesma do currículo: *Suporte de TI, júnior; runbooks e
laboratórios de escritório*) e a cidade. Uma foto é opcional aqui de um jeito que não é no currículo; um
avatar serve.

**Os repositórios fixados** são o que a página mostra primeiro. O GitHub deixa fixar até seis; fixe **os um a
três que são evidência**, em ordem de força, e mais nada. Cada um precisa de uma descrição de uma linha que
diga o que é, do mesmo jeito que a primeira frase do README, e de alguns tópicos para uma busca achar.

**A primeira tela do README** é a aula 16 do curso de portfólio: o que é, para quem, uma imagem e como ver
funcionando.

**Um arquivo ou o histórico** é o último clique, e quem avalia procura se o código ou a configuração é
legível e se os commits contam uma história. Os dois foram construídos no curso de portfólio; aqui eles são
só onde o caminho termina.
