---
title: O que fecha a aba
version: 1
---

As visitas que terminam cedo terminam pelos mesmos poucos motivos, e cada um tem uma correção de uma tarde:

- Quarenta repositórios com o mesmo peso. Tutoriais, exercícios de curso, forks nunca mexidos. Quem
  avalia não sabe qual abrir. **Fixe a evidência**, e arquive ou torne privado o que é só prática. Nada
  precisa ser apagado; precisa parar de competir.
- Clones de tutorial apresentados como projetos. Um repositório com o nome de um curso, com o código do
  curso, parece trabalho do curso. Mude-o como a aula 2 do curso de portfólio descreve, ou deixe-o fora dos
  fixados.
- **Um repositório sem README**, ou com o modelo que a ferramenta gerou. Quem avalia não tem o que ler,
  então não lê nada.
- **Descrições vazias ou que dizem *meu projeto*.** A descrição de uma linha é o que um repositório fixado
  mostra; é a linha mais barata de acertar no perfil inteiro.

Um **README de perfil** (um repositório com o mesmo nome da sua conta, cujo README o GitHub mostra no topo
do perfil) é opcional. Se escrever um, limite-o ao que falta na página: duas linhas sobre o que você faz e um
link para o projeto. Um muro de selos e estatísticas animadas é o tipo de coisa que a aula 16 do curso de
portfólio mandou cortar de um README, pelo mesmo motivo.
