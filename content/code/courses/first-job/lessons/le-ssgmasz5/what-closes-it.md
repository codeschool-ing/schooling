title: What closes the tab
version: 1
---

The visits that end early end for the same few reasons, and each has a fix that takes an afternoon:

- Forty repositories of equal weight. Tutorials, course exercises, forks never touched. The reviewer
  cannot tell which one to open. **Pin the evidence**, and archive or make private what is only practice.
  Nothing needs deleting; it needs to stop competing.
- Tutorial clones presented as projects. A repository named after a course, with the course's code,
  reads as the course's work. Either change it as lesson 2 of the portfolio course describes, or keep it
  out of the pinned list.
- **A repository with no README**, or with the template the tool generated. The reviewer has nothing to
  read, so they read nothing.
- **Descriptions that are empty or say *my project*.** The one-line description is what a pinned repository
  shows; it is the cheapest line on the whole profile to get right.

A **profile README** (a repository with the same name as your account, whose README GitHub shows at the top
of the profile) is optional. If you write one, keep it to what the profile page lacks: two lines about what
you do and a link to the one project. A wall of badges and animated statistics is the kind of thing lesson
16 of the portfolio course asked you to cut from a README, for the same reason.
