**The profile page** has to say, in the few lines above the repositories, **who you are and what you do**:
your real name, one line (the same line as the CV: *IT support, junior; runbooks and small-office labs*),
and the city. A photo is optional here in a way it is not on a CV; an avatar is fine.

**The pinned repositories** are what the page shows first. GitHub lets you pin up to six; pin **the one to
three that are evidence**, in order of strength, and nothing else. Each needs a description of one line
that says what it is, the same way the README's first sentence does, and a few topics so a search finds it.

**The README's first screen** is lesson 16 of the portfolio course: what it is, for whom, a picture, and
how to see it working.

**One file or the history** is the last click, and the reviewer is looking for whether the code or the
configuration is readable and whether the commits tell a story. Both were built in the portfolio course;
here they are simply where the path ends.
