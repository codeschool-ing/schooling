---
title: One value, and everybody else reads it
version: 1
---

**A screen shows the same fact in more than one place, and the fact must live in exactly one.** The
planner's course screen lists the week's sessions, ticks the ones that are done, and prints the
week's total at the bottom. Three things on the screen, one fact underneath: which sessions are done.
If the list kept its own copy of `done` and the total kept another, a tap would change one copy and
the screen would show two answers at once.

The belief to drop is that a view holds its data the way an object in a class-based toolkit does,
with a label that keeps its text and a checkbox that keeps its state, and some code that copies
between them after every change. SwiftUI turns that round. **A view is a description computed from
data, and the data has one owner.** Every other view that needs it either reads it, or is handed a
way to change it in the owner's place. Lesson 3 showed that a view's `body` runs again whenever
what it read changes; this lesson is about where that data lives and who may write it.

SwiftUI's documentation calls the owner the **source of truth**, and gives two tools for the
simplest case, a value owned by one view and changed by its children:

- `@State` marks a property as storage the view owns. Section 03 is about it.
- `@Binding` marks a property as a way to read and write somebody else's storage. Section 04 is
  about it, and section 05 builds one by hand so you can see that there is no magic in it.

**Everything that can be computed from the source of truth is computed, not stored.** The week's
total is a function of the plan, lesson 1's `weekTotal(today:)`. Store it beside the plan and it is
a second source of truth that disagrees the first time somebody forgets to update it; section 06
shows that happening, in a test that fails.

Lesson 7 moves the planner's state into an object several screens share, which is what an app with
more than one screen needs. The rule does not change there: one owner, and everybody else reads or
is handed a binding.
