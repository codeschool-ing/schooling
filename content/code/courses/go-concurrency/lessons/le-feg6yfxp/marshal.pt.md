JSON é como a maioria dos programas escritos hoje conversa entre si, e o `encoding/json` é como um
programa Go o fala. **O pacote trabalha a partir dos seus tipos: você descreve os dados uma vez,
como uma struct, e a mesma descrição serve para escrever JSON e para lê-lo de volta.** Esta seção é
a metade da escrita. O trabalho desta lição mora em `~/jsondemo`, criado com
`go mod init example.com/jsondemo`, e o primeiro programa é um pedido com dois itens, salvo como
`order.go`:

## O que cada linha da saída diz

**A primeira linha é o pedido inteiro em JSON compacto**, e toda regra do tipo aparece nela. As
chaves são os nomes que as tags deram, `price_cents` e não `Cents`. O slice virou um array e cada
`Item` um objeto dentro dele. O horário virou `"2026-10-16T14:30:00Z"`, a forma RFC 3339, porque o
`time.Time` sabe se escrever como JSON; a lição 20 fala mais de horários. Não há `note`, porque o
`omitempty` tirou a string vazia, e não há `internal`, porque nada fora do pacote enxerga um campo
não exportado, o `encoding/json` incluído.

**O bloco indentado é o mesmo tipo de valor escrito por um `Encoder`**, direto na saída padrão. O
`Encode` também escreve uma quebra de linha depois de cada valor, e é por isso que um valor JSON por
linha, um formato chamado JSON Lines, é a coisa natural para um `Encoder` produzir.

**A última linha é a recusa.** `json: unsupported type: chan bool`: um canal, uma função e um número
complexo não têm forma em JSON, e pedir uma é um erro, e não um valor vazio.

## A tag, por inteiro

Uma tag é uma string que o compilador guarda ao lado de um campo e que o `encoding/json` lê em tempo
de execução. O formato dela é a chave, depois uma vírgula e as opções:

| tag | efeito |
|---|---|
| `json:"sku"` | a chave é `sku` |
| `json:"note,omitempty"` | a chave é `note`, e o campo fica de fora quando guarda o seu zero value |
| `json:"retired,omitzero"` | fica de fora quando é o zero value, julgado de um jeito que a seção 04 mostra que importa |
| `json:"-"` | nunca escrito e nunca lido, seja qual for o valor |
| `json:",string"` | um número ou um bool escrito dentro de uma string, `"42"` em vez de `42` |

**`json:"-"` é como se mantém dentro do programa um campo que não pode sair**, um hash de senha ou
um identificador interno, quando o campo precisa ser exportado por outros motivos. Uma tag com erro
de digitação não é um erro que o compilador vê; o `go vet` confere se cada tag tem o formato certo,
mais um motivo para rodá-lo.
