title: The loop a model lives in
version: 1

**A model is not finished when it is trained.** It is used for months, on members it never saw,
while the shop it learned from changes; it is checked against outcomes that arrive late; and it is
trained again, by a process that has to produce the same thing every time it runs. That loop is the
**model lifecycle**, and most of it is data work.

| stage | what happens | whose it is | the lesson |
| --- | --- | --- | --- |
| **data** | the shop's tables land, complete, on time | data engineer | `pipelines-etl` |
| **features and labels** | rows become examples as of a cutoff, labels only when matured | data engineer, with the modeller | 3, 5 and 6 |
| **training** | an algorithm is fitted to a validated training set | modeller, run by the platform | 5 and 7 |
| **evaluation** | the model is scored on a later, untouched cutoff, beside a baseline | modeller decides the score, platform computes it | 4 and 5 |
| **registration** | the model, its data and its scores are stored together under a version | data engineer | 7 |
| **deployment** | the model answers where it is asked: a nightly table, a web service, a device | data engineer | 8 |
| **monitoring** | latency, cost, input data and, when the labels arrive, quality | data engineer | 9 |
| **retraining** | a trigger, a new candidate, a comparison, a swap or a refusal | both | 10 |

**The modeller owns one column of decisions: which algorithm, which features are worth trying,
which score is right.** The platform owns everything that has to happen the same way every time,
which is most of the rows. That division is why this course exists, and it is also where projects
fail: a model that a modeller built once in a notebook, on data they gathered by hand, and that
nobody can rebuild when the person who made it has moved on.

**In this course one person, Ana, plays both parts.** That is common in a small company, and it
makes the boundary easy to forget. The rest of this lesson draws it on purpose: the scripts from
lessons 1 to 4 were a modeller's; the ones below are the platform's.
