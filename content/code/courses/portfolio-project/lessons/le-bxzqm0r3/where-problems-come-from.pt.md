title: De onde vêm bons problemas
version: 1

O formato vem da sua trilha; o problema em si precisa vir de algum lugar, e os melhores vêm de onde **uma
pessoa real tem um incômodo real**. Quatro lugares para procurar:

- **O seu trabalho anterior, em qualquer área.** Uma loja, uma clínica, a secretaria de uma escola, um
  depósito: cada um tem uma folha de papel, uma planilha ou uma rotina que alguém detesta. O loanbook é
  exatamente isso.
- **Uma organização pequena que você conhece.** Um clube, uma igreja, um projeto comunitário, o negócio
  de um parente. Organizações pequenas têm problemas reais e nenhum orçamento, e você pode perguntar do
  que precisam.
- **Um conjunto de dados ou uma API pública** com uma pergunta que ninguém respondeu do jeito que você
  responderia. Dados abertos de uma prefeitura ou de um órgão público costumam ser mais bagunçados e mais
  interessantes do que um conjunto de dados didático.
- **Uma ferramenta que você quis que existisse** enquanto estudava esta trilha. Se você precisou, outras
  pessoas no seu nível também, e você sabe exatamente o que ela tem de fazer.

Duas fontes a evitar. **O clone de um produto famoso**, porque convida a uma comparação com uma equipe de
centenas que você não tem como vencer, e já está na pilha de tutoriais da aula 2. E **uma ideia que
precisa de usuários para valer alguma coisa**, como um marketplace ou uma rede social: sem usuários é uma
tela vazia, e não dá para conseguir usuários em seis semanas.

Uma pessoa real tem mais uma vantagem: **ela dá um briefing**, que é a aula 4.
