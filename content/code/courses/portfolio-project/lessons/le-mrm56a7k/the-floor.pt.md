title: O que é o piso
version: 1
---

O padrão é a **WCAG 2.2**, as Diretrizes de Acessibilidade para Conteúdo Web, e o nível que quase toda
organização pede é o **AA**. Ele tem dezenas de critérios. Para um projeto pequeno, sete verificações
cobrem a maior parte do que quem avalia, ou um usuário de verdade, vai encontrar:

| verificação | o que quer dizer no loanbook |
|---|---|
| todo campo tem **rótulo** | o campo de nome diz de quem é o empréstimo, e continua visível enquanto se digita |
| tudo funciona **pelo teclado**, com foco visível | o Tab chega a todo campo e botão, e dá para ver onde se está |
| o texto tem **contraste** de pelo menos 4,5:1 | o cinza sobre o branco é escuro o bastante para ler num corredor |
| **títulos e marcos** indicam a estrutura | um `h1`, o conteúdo dentro de `main`, os cabeçalhos da tabela marcados como tal |
| as mudanças são **anunciadas** | *emprestado até o dia 13* é lido em voz alta, não só desenhado |
| funciona em **320 pixels** sem rolagem lateral | a tabela vira uma lista num celular pequeno |
| os alvos de toque têm pelo menos **24 pixels** | um dedo aperta *Return* sem apertar o vizinho |

Nenhum desses é caro quando feito enquanto a página é construída, e cada um é caro de acrescentar a uma
página construída sem ele. É por isso que a aula 6 pôs a acessibilidade no piso, junto com o que nunca se
corta.

E há um motivo de portfólio além dos usuários. **Acessibilidade é algo que quem avalia verifica em um
minuto**, com o teclado e uma ferramenta, e poucos portfólios de júnior passam. Uma página que passa é
notada por isso.
