1. **It runs from its README on somebody else's machine.** Not yours, where everything is already
   installed. Lesson 16 tests this on a clean machine.
2. **It has an address, or a recording of the deploy.** Something the reader can open without
   installing anything. Lesson 15.
3. **It tests the rule most likely to break.** Not everything; the one rule whose failure would be
   wrong rather than ugly. Lesson 12.
4. **It writes down two or three decisions**, with what each one cost. Lesson 16 again, in the README.
5. **You can explain every part of it.** If there is a file you copied and could not rewrite, it is
   not finished yet. Lessons 19 and 20.

Notice what the list leaves out. It does not ask for many features, a particular language or a
cloud provider. A project with one screen that meets all five is finished. A project with thirty
features that meets two is not, and **finished is the property a reader is checking first**.

The figure puts five tutorials beside one project. The tutorials tick the first line five times,
because each tutorial wrote a README that works. The project ticks every line once. A reviewer is
counting lines.
