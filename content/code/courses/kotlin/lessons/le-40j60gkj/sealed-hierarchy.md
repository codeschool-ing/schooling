---
title: A sealed class: a fixed set of shapes
version: 1
---

An enum is a fixed set of values. **A sealed class is a fixed set of types**, each of which can carry
its own data. Its subclasses must be declared in the same package and module, so the compiler sees
every one of them, and nobody can add another from outside.

## What the compiler knows

`describe` has no `else`, and the compiler accepts it, because **the three `is` branches are every
possible `Session`**. That is the same knowledge it had about the enum's values, now about types.

Compare the data class of lesson 8 with a status field: `Session(course, minutes, status, startedAt:
String?)`. A planned session would carry a `startedAt` of `null`, a running session's `minutes` would
mean nothing, and every function would have to remember which fields are meaningful for which status.
**In the sealed version each shape has the fields it needs and no others**, and the compiler checks
that the code asking for `startedAt` is in a branch where there is one.

## `is` checks a type; nothing is a string

The branches test types. There is no status string to misspell, no `ordinal` to save, and no way to
build a `Running` without a start time. A session is one of three things, and its type says which.
