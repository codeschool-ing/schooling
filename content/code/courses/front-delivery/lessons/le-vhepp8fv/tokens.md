**A token is a named value that stands for a design decision.** `#2f6f4e` is a colour; `color-green-600`
is a token for it; `accent` is a token for *what that colour is used for*. The difference between the last
two is the whole idea, and it is why tokens come in layers.

| layer | example | says |
|---|---|---|
| primitive | `color-green-600: #2f6f4e` | here is a colour the brand owns |
| semantic | `accent: {color.green-600}` | this is the colour of things you can act on |
| component | `button-background: {accent}` | a button's background is the action colour |

**Code refers to semantic tokens, never to primitives.** A stylesheet that says `color: var(--accent)`
survives the brand green being replaced, a dark theme that needs a lighter green to stay readable, and a
partner product that wants its own accent. One that says `var(--color-green-600)` survives none of them,
because it tied a meaning to a particular paint.

## Primitives are a palette, not a menu

The primitives are every value the system allows, and nothing more: a dozen greys, a few greens, a scale
of sizes. Nobody picks from them while building a screen. The semantic layer picks from them once, per
theme, and a screen picks from the semantic layer. When somebody needs a colour the semantic layer does
not have, that is a conversation about the system, not a hex code in a stylesheet.

**Component tokens are optional**, and the planner does without them. They earn their place when one
component needs to diverge from the meaning it would otherwise inherit, and many systems never write one.
A third layer nobody needs is a layer somebody has to keep in step for nothing.

## What a token is not

A token is not a CSS variable, though the planner's become CSS variables. It is a decision held as data,
and CSS is one of the places it is written out to. The same file can produce an Android resource file, an
iOS asset catalogue, or the variables of a design tool, which is how a designer and a developer end up
using the same `accent` rather than two hexes that drifted apart. The next section writes the planner's
as data.
