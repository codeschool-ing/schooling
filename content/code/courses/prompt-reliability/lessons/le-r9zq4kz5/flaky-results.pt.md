Com temperatura 0 o substituto escolhe o rótulo de maior pontuação, então o mesmo prompt dá as mesmas
respostas em toda execução. Acima de 0 ele sorteia, como a aula 8 mostrou. Aqui está o mesmo prompt
rodado duas vezes com temperatura 1, mudando só a semente:

```
ana@lab:~/triage$ pl run prompts/v3-examples.txt cases/dev.jsonl --set temperature=1 --out runs/hot-a.jsonl
40 calls, prompt 1d9c6ec4, written to runs/hot-a.jsonl
ana@lab:~/triage$ pl run prompts/v3-examples.txt cases/dev.jsonl --set temperature=1 --seed 7 --out runs/hot-b.jsonl
40 calls, prompt 1d9c6ec4, written to runs/hot-b.jsonl
ana@lab:~/triage$ pl compare runs/hot-a.jsonl runs/hot-b.jsonl
runs/hot-a.jsonl         passes 31/40
runs/hot-b.jsonl         passes 28/40
fixed 5, broken 8, still passing 23, still failing 4
broken: t06 t11 t15 t23 t30 t32 t34 t36
sign test on the 13 that changed: p = 0.581
```

31 e 28. Treze mensagens mudaram entre duas execuções de um mesmo prompt. Se fossem dois prompts, o
primeiro pareceria três casos melhor, e **uma execução de cada é tudo o que a maioria das comparações
recebe.**

Um teste que aprova e reprova a mesma entrada em chamadas diferentes é o que programadores chamam de
instável, *flaky*. Aqui a instabilidade não é um defeito do teste; é justamente a coisa medida.

discordância estável sobre urgência que já era com temperatura 0. `t21` falhou em uma chamada de
cinco, `t05` e `t23` em quatro, e `t23` passa sempre com temperatura 0.

São três descobertas diferentes. Um caso que falha em toda chamada é um defeito no prompt, ou no
rótulo, e uma execução o encontra. Um caso que falha em algumas chamadas é uma taxa, e só amostras o
encontram. Um caso que passa com temperatura 0 e falha acima dela diz que o parâmetro faz parte do
prompt.

## O que custa

Cinco amostras são cinco vezes as chamadas: 200 em vez de 40, e a aula 16 põe preço em cada uma.
Ainda é o erro mais barato. Com modelos reais, nem a temperatura 0 garante respostas idênticas de uma
chamada para a outra, então o hábito protege você ali também. **Nunca informe uma comparação entre
dois prompts a partir de uma execução de cada** quando algum deles foi sorteado; informe as taxas, e
o número de amostras ao lado.
