Propriedades personalizadas são **herdadas**, como `color` e `font-family` na seção 10 da aula 5. Um valor declarado em `:root` é visível para todo elemento porque todo elemento descende da raiz. E um valor declarado em qualquer outro elemento é visível para esse elemento e tudo dentro dele, e para nada mais. Foi esta a linha que deixou o segundo título vermelho:

```css
.cancelled { --accent: var(--red); }
```

```
ana@laptop:~/site$ probe events.html style .cancelled --accent style .event border-left-color
article.event.cancelled  --accent: #8a1c1c
article.event  border-left-color: rgb(47, 111, 78)
article.event.cancelled  border-left-color: rgb(138, 28, 28)
```

O evento cancelado declara `--accent` de novo, como o vermelho. Dentro dele, todo `var(--accent)` encontra esse valor primeiro, porque o ancestral mais próximo que declara uma propriedade personalizada é o que conta. A borda e o título dele são vermelhos; os do outro evento são verdes; e as regras que os desenham são as mesmas duas regras.

## Para que serve o escopo

Este é o padrão das **variantes**: um componente lê cores e tamanhos de propriedades personalizadas, e uma variante só muda as propriedades. Um evento cancelado, um evento em destaque, um livro esgotado: cada um é uma linha que define `--accent`, em vez de uma regra para cada parte do cartão que precisa mudar de cor. Acrescentar depois uma parte nova ao cartão, um ícone ou um botão, é escrever `var(--accent)` uma vez, e toda variante acompanha.

É também como um componente pode ser configurado de fora sem ninguém mexer no interior dele: uma página que quer cartões menores define `--space: 0.75rem` no contêiner, e os cartões lá dentro usam o valor. Isso mantém os seletores curtos e a especificidade baixa e uniforme, que é o que a seção 08 da aula 5 pediu.
