A aula 8 terminou a seção de quebra de linha com a regra que decide entre os dois, e vale pô-la primeiro aqui: **o Flexbox monta coisas em uma dimensão, o Grid em duas.** Um contêiner flex põe itens ao longo de uma linha e, se quebra, começa outra linha que não sabe nada da primeira. Um contêiner grid tem **colunas e linhas definidas no próprio contêiner**, e todo item fica numa célula dessa estrutura, então os itens de linhas diferentes se alinham entre si.

O teste prático: **os itens precisam se alinhar nas duas direções?** Uma galeria de capas em que cada coluna deve ser uma linha reta descendo a página é um grid. Uma fileira de etiquetas cujo número varia e que deve só quebrar como palavras é Flexbox. Uma página com cabeçalho, barra lateral e rodapé é um grid. O menu dentro do cabeçalho é Flexbox. A maioria das páginas usa os dois, aninhados: Grid para a forma grande, Flexbox dentro das peças.

Há uma segunda diferença que ajuda a escolher. No Flexbox, **os itens decidem**: o conteúdo e os valores `flex` deles calculam os tamanhos, e o contêiner acompanha. No Grid, **o contêiner decide**: ele declara as trilhas, e os itens são postos nelas. Quando você conhece a estrutura de antemão, o Grid a declara diretamente; quando a estrutura deve sair do conteúdo, o Flexbox a encontra.

## Vocabulário

O Grid tem algumas palavras que vale fixar agora, porque as propriedades têm o nome delas:

- **Contêiner grid**: o elemento com `display: grid`. Os filhos diretos dele são **itens grid**, a mesma regra do Flexbox.
- **Trilha** (*track*): uma coluna ou uma linha.
- **Linha do grid** (*grid line*): a linha entre duas trilhas, ou em cada borda. Três colunas têm quatro linhas de coluna.
- **Célula**: o espaço onde uma linha e uma coluna se cruzam. **Área**: um retângulo de uma ou mais células.
- **Gap**: o espaço entre trilhas, a mesma propriedade `gap` do Flexbox.
