Uma página tem regiões que todo visitante aprende a reconhecer: a faixa no topo com o logotipo, o menu, o conteúdo principal, talvez uma barra lateral, e o rodapé. O HTML tem um elemento para cada uma, e cada uma vira um **landmark** (ponto de referência) na árvore de acessibilidade, uma região que um leitor de tela consegue listar e para onde consegue pular:

| elemento | papel de landmark | o que vai dentro |
| --- | --- | --- |
| `<header>` | banner | o nome ou o logotipo do site, muitas vezes o menu principal |
| `<nav>` | navigation | um conjunto de links para se locomover |
| `<main>` | main | o conteúdo para o qual esta página existe |
| `<aside>` | complementary | relacionado mas à parte: uma barra lateral, uma caixa de links |
| `<footer>` | contentinfo | o endereço, os direitos autorais, links para políticas |

## As regras que vêm com cada um

**`<main>` aparece uma vez.** É a parte que muda de página para página, e um link de pular, "pular para o conteúdo principal", é um link para ele. A página sopa não tem nenhum, e o axe apontou **landmark-one-main** nela.

**`<nav>` é para a navegação principal, não para qualquer grupo de links.** O menu principal é um; uma trilha de navegação (*breadcrumb*) pode ser outro. Os três links no fim de um artigo não são. Quando uma página tem mais de um `<nav>`, nomeie cada um com `aria-label`, como a página inicial fez com `aria-label="Main"`, para que um leitor de tela diga "navegação Main" e "navegação Breadcrumb", e não "navegação" duas vezes.

**Um `<header>` ou `<footer>` só é landmark no nível de cima.** Dentro de um `<article>` ou de uma `<section>`, os mesmos elementos querem dizer "o cabeçalho deste artigo" e "o rodapé deste artigo", e não são landmarks. A próxima seção mostra a árvore exatamente desse caso, porque surpreende.

**Tudo o que é visível deve ficar dentro de algum landmark.** A regra **region** do axe aponta conteúdo fora de todos eles, porque quem pula de landmark em landmark nunca chega até ele. Na página sopa ela encontrou três elementos assim.

## Landmarks de graça

Nada disso precisa de atributo. `role="navigation"` existe e faz o mesmo que `<nav>`, e você vai encontrá-lo em código antigo, escrito antes de os elementos existirem. **A primeira regra de uso do ARIA**, a especificação que define esses papéis, é não usá-lo onde um elemento HTML já faz o serviço, porque o elemento traz o papel, o comportamento de teclado e o tratamento do navegador junto, e um atributo traz só o papel.
