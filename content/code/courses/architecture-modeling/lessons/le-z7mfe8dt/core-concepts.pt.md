**O modelo de conceitos centrais (BACCM) do BABOK, o *Business Analysis Core Concept Model*, nomeia
seis conceitos presentes em toda mudança, e diz que a análise de negócio consiste em entender os
seis e como eles se relacionam.** É a página mais útil do guia para um arquiteto, porque é uma lista
de verificação pequena o bastante para caber na cabeça.

| conceito | o que é | a conciliação de Joana |
| --- | --- | --- |
| **Mudança** | o ato de transformar, em resposta a uma necessidade | passar da conferência manual mensal para uma automática diária |
| **Necessidade** | um problema ou oportunidade a tratar | o financeiro precisa de dois dias por mês para fechar, e as divergências chegam aos auditores |
| **Solução** | um jeito específico de atender necessidades num contexto | um job de conciliação que compara os arquivos de liquidação do gateway com os pagamentos do Carcará, com uma tela para as exceções |
| **Stakeholder** | um grupo ou pessoa com relação com a mudança, a necessidade ou a solução | Joana, o diretor financeiro, Pagamentos, Vendas, os auditores externos, a empresa de pagamento |
| **Valor** | o quanto algo vale, importa ou serve para um stakeholder | dois dias por mês devolvidos ao financeiro; menos apontamentos de auditoria; detecção mais cedo de um erro do gateway |
| **Contexto** | as circunstâncias que influenciam a mudança e são influenciadas por ela | o formato de arquivo do gateway; as regras fiscais brasileiras; os reembolsos em dinheiro nos guichês das rodoviárias, que o gateway nunca vê; o volume do São João |

## Os conceitos estão ligados

O uso de verdade do modelo está nas relações. Cada conceito se define em termos dos outros: uma
solução atende a uma necessidade, num contexto, entregando valor a stakeholders, por meio de uma
mudança. Então uma lacuna num deles aparece como pergunta sobre outro:

- *Que necessidade esta solução atende?* Se ninguém sabe dizer, a solução veio primeiro.
  **Automatizar a conciliação** era uma solução; a necessidade apareceu quando alguém perguntou a
  Joana para que servem os dois dias.
- *Valor para quem?* O diretor financeiro valoriza fechar o mês mais rápido. Pagamentos valoriza não
  ser acionado de madrugada por um job que falha num arquivo malformado. Os dois são valor; puxam
  para lados diferentes.
- *O que no contexto poderia mudar a solução?* O gateway anunciou um formato novo de arquivo de
  liquidação para o ano que vem. Uma solução construída sobre o formato de hoje tem data de
  validade.

## Usando na segunda-feira

Antes de um workshop de requisitos, escreva os seis títulos numa página e preencha o que você sabe.
Os vazios são a pauta. Quando Tainá fez isso para a conciliação, **contexto** era o mais vazio:
ninguém na sala sabia que os agentes de guichê reembolsam em dinheiro, no balcão, passagens
compradas com cartão, então o dinheiro sai pelo back office e o gateway nunca fica sabendo. Esse
único fato mudou a solução, e veio de uma pergunta que o modelo tornou óbvia.
