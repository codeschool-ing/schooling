## Lendo o mapa

- **Frota → Vendas, com uma camada anticorrupção.** A Frota é upstream: foi comprada em 2009, seu
  modelo de *viagem programada* tem quarenta campos e códigos de que ninguém na Carcará se lembra, e
  ela não vai mudar. Vendas a traduz para a sua própria *Trip* na fronteira. Antes do mapa, essa
  tradução estava espalhada por onze classes; o mapa deu nome à camada, e o time levou a tradução
  para um lugar só.
- **Preços → Vendas, cliente e fornecedor.** Preços é upstream, mas as necessidades de Vendas contam
  no planejamento dele: quando Vendas precisa de uma cotação de tarifa para reserva de grupo, Preços
  põe isso na agenda.
- **Vendas → Embarque, serviço de host aberto com linguagem publicada.** Vendas publica a lista de
  passagens do dia num formato documentado, e Embarque é **conformista** a ele. Esse formato também é
  o que os celulares dos motoristas guardam offline, e é por isso que mudá-lo exige um plano de
  migração para 300 celulares.
- **Gateway de pagamento → Pagamentos, com uma ACL.** O gateway é o serviço de host aberto de outra
  empresa; o contexto de Pagamentos da Carcará traduz os status dele para os da própria Carcará.
- **Vendas e Notificações, host aberto e conformista.** Notificações recebe os eventos *passagem
  vendida*, *passagem cancelada* e *viagem alterada* do jeito que Vendas os publica.
- **Finanças, caminhos separados.** Finanças lê os arquivos de liquidação do gateway e não se integra
  com Vendas de jeito nenhum. Isso é uma decisão, e desenhada como decisão ela pode ser questionada:
  também é por isso que a conciliação mensal toma dois dias de Joana.

## O que o mapa mudou

Três decisões saíram de um desenho só, o que é típico:

1. A ACL entre Frota e Vendas virou um componente com testes próprios, e a atualização seguinte da
   Frota quebrou uma classe em vez de onze.
2. A linguagem publicada para Embarque ganhou um número de versão, para que uma mudança nela possa
   ser distribuída enquanto celulares antigos continuam rodando.
3. A linha de *caminhos separados* até Finanças foi reaberta, e a aula 7 acompanha o trabalho de
   requisitos que saiu daí.
