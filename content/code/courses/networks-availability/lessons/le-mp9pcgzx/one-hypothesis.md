When something stops working, the first reflex is to change things: restart the router, reinstall the
driver, reboot the laptop, try another browser. Sometimes the fault goes away, and **nobody learns what
it was**, so it comes back and costs the same again. Diagnosis is the other habit: say what you think is
wrong, choose a test whose result could prove you wrong, run it, and read the answer before touching
anything.

The layers of lesson 1 of `networks` put the questions in order. Every layer depends on the ones
beneath it, so a test that passes at one layer clears every layer it depended on. A ping that comes back
from the web server says, in one command, that the cable, the addresses and every route between here and
there are working. **A test that passes rules out everything under it; a test that fails points at the
layer it tested or one below.**

There are three ways to walk the layers, and each suits a different report:

| method | where it starts | when it fits |
|---|---|---|
| bottom-up | the link: is there a carrier, an address, a gateway? | one machine is cut off from everything |
| top-down | the application: what exactly does it say? | one program fails while others work |
| divide and conquer | the middle: does a ping to the far end come back? | you do not know yet, which is most of the time |

Divide and conquer is the default because **one command halves the search**. If a ping to the server's
address comes back, the fault is above IP: a name, a port, a program. If it does not, it is at IP or
below: a route, a link, a firewall. Then you halve what is left.

Two rules keep the method honest. **Change one thing at a time**, or you cannot tell which change
mattered. And put back what you changed when it made no difference, or the next person debugs your
experiment as well as the fault.

**How a command fails is itself a measurement.** Two `curl` runs in the next two sections print the same
words, `Couldn't connect to server`, one after 3057 ms and the other after 0 ms, and they are two
different faults at two different layers. Read the error, and read the time it took.
