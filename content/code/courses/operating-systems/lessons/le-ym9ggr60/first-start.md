Most screens are quick:

- **Region and keyboard.** For an office in Brazil, *Brazil* and the **Portuguese (Brazil ABNT2)**
  layout, the one with *ç* on the keyboard. The wrong layout is the most common reason a new user's
  password "does not work": the characters they type are not the ones they think.
- **Network.** Setup wants the internet, to fetch updates and to sign in. Connect the cable or the
  office Wi-Fi.
- **Device name.** Setup invents one like `DESKTOP-7Q2K4M1`. Give it a name that says which machine it
  is, like `OFFICE-PC-03`, because that name is what appears in the network, in the router and in every
  support conversation from now on.
- **PIN.** **Windows Hello** asks for a PIN, which unlocks this one computer only. It is not the account's
  password, and it never travels over the network.
- **Privacy.** Location, diagnostic data, tailored ads. For an office, turn off what is not needed,
  and write down what you chose so every machine gets the same answers.

## The account

The one screen that deserves thought is **who is this computer for**. There are three kinds of answer:

| | what it is | typical use |
|---|---|---|
| **Microsoft account** | an email address, managed by Microsoft | a personal computer |
| **work or school account** | an account in the organisation's directory (Microsoft Entra ID) | a company computer, managed centrally |
| **local account** | exists only on this computer | a shared or offline machine |

Setup steers firmly towards a Microsoft account, and the ways to create a local account instead change
between versions of Windows. In a company, the right answer is usually the second: the computer is
joined to the organisation, so its settings, its encryption key and the people allowed to sign in are
decided centrally. A reception PC set up with the receptionist's personal Microsoft account is a
computer that, legally and practically, belongs to them.
