Four more kinds of Windows turn up in support work, and each answers a different need.

## LTSC: the one that does not change

**Windows 11 Enterprise LTSC** (*Long-Term Servicing Channel*) receives **security updates only, for
years**, and never a feature update. No new apps appear, no settings move. It is meant for machines
that must behave the same on the last day as on the first: a hospital device, a factory terminal, a
cash register. The IoT variant of LTSC 2024 is supported for ten years.

It is **not** a better Windows for office PCs. Programs expect a recent Windows, and some, such as the
Microsoft Store and its apps, are left out.

## Windows Server

Same kernel, different job. **Windows Server 2025**, in *Standard* and *Datacenter*, runs Active
Directory, file shares, and virtual machines. It is licensed **per processor core**, and the two
editions differ mainly in how many virtual machines one licence covers. It has no Microsoft Store and,
installed as *Server Core*, no desktop at all: lesson 3's server with no graphical interface, Windows
edition.

## Windows on Arm

Some laptops, including every **Copilot+ PC** built on Snapdragon, have an Arm processor rather than
an Intel or AMD one. Windows runs natively, and programs built for x64 run through an emulator called
**Prism**. Most work; old drivers and some anti-cheat and VPN software do not. That is lesson 1's
point about drivers being written for one piece of hardware, arriving in a new place.

## N editions

In Europe, **Windows 11 Pro N** and **Home N** are sold without some media apps, for competition
reasons. They are otherwise identical, and the missing pieces are a free download called the *Media
Feature Pack*. A video call that fails on one office PC and works on the next can be exactly this.
