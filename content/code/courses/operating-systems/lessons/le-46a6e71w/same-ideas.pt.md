Antes dos detalhes de cada sistema, as partes que todos têm. Quando você sabe o nome delas, achá-las
numa tela desconhecida é questão de olhar nos poucos lugares onde cada sistema as põe.

1. **Um lugar para abrir programas e buscar**: o Iniciar no Windows, o Spotlight e o Launchpad no
   macOS, as Atividades no GNOME. Nos três, **digitar o nome** do que você quer é mais rápido do que
   procurar.
2. **Uma faixa de programas abertos e fixados**: a barra de tarefas, o Dock, o Ubuntu Dock.
3. **Um canto do sistema**: o relógio, a rede, o som, a bateria, e um caminho para as configurações.
4. **Janelas**, cada uma com botões para minimizar, maximizar e fechar.

E, por trás delas, as mesmas quatro ferramentas em todo sistema:

| | Windows 11 | macOS | Ubuntu (GNOME) |
|---|---|---|---|
| gerenciador de arquivos | Explorador de Arquivos | Finder | Arquivos |
| configurações | Configurações (e o velho Painel de Controle) | Ajustes do Sistema | Configurações |
| o que está rodando | Gerenciador de Tarefas | Monitor de Atividade | Monitor do sistema |
| um terminal | Terminal, com PowerShell | Terminal | Terminal |

A última linha é a aula 8. A linha de cima dela é a lista de processos da aula 1 com uma janela em
volta.

## Um desktop não é o sistema

No Windows e no macOS o desktop vem com o sistema e não pode ser trocado. **No Linux ele é um pacote
entre muitos**: o Ubuntu traz o GNOME, o Linux Mint traz o Cinnamon, o Kubuntu traz o KDE Plasma, e o
servidor da aula 3 não traz nenhum. Quando alguém diz "o Linux é assim", está descrevendo um desktop. As
ideias acima continuam lá, em outros lugares.
