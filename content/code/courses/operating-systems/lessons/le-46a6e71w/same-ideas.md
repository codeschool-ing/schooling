Before any system's details, the parts they all have. Once you can name these, finding them on an
unfamiliar screen is a matter of looking in the few places each system puts them.

1. **A place to start programs and search**: Start on Windows, Spotlight and Launchpad on macOS,
   Activities on GNOME. On all three, **typing the name** of what you want is faster than finding it.
2. **A strip of running and pinned programs**: the taskbar, the Dock, the Ubuntu Dock.
3. **A system corner**: the clock, the network, the sound, the battery, and a way into the settings.
4. **Windows**, each with buttons to minimise, maximise and close.

And, behind them, the same four tools on every system:

| | Windows 11 | macOS | Ubuntu (GNOME) |
|---|---|---|---|
| file manager | File Explorer | Finder | Files |
| settings | Settings (and the old Control Panel) | System Settings | Settings |
| what is running | Task Manager | Activity Monitor | System Monitor |
| a terminal | Terminal, with PowerShell | Terminal | Terminal |

The last row is lesson 8. The row above it is lesson 1's process list with a window around it.

## A desktop is not the system

On Windows and macOS the desktop comes with the system and cannot be swapped. **On Linux it is one
package among many**: Ubuntu ships GNOME, Linux Mint ships Cinnamon, Kubuntu ships KDE Plasma, and
lesson 3's server ships none. When somebody says "Linux looks like this", they are describing one
desktop. The ideas above are still there, in different places.
