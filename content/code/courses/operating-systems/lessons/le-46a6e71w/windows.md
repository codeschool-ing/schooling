The *Start* button opens a list of pinned apps and a search box that is already listening: press
the *Windows key* and type. *Right-clicking* Start, or *Windows+X*, opens a plainer menu that
support work uses constantly: Device Manager, Disk Management, Terminal, Settings, shut down.

Quick settings, at the bottom right, is **Windows+A**. When the Wi-Fi icon "is gone", it is usually in
there, or hidden behind the **^** arrow beside it.

## File Explorer

**Windows+E** opens it. Three habits make it useful:

- *The address bar takes a path.* Click in it, or press **Alt+D**, and type `C:\Users` or
  `%APPDATA%`. It is faster than clicking, and it is exact when you dictate it over the phone.
- *Show file extensions.* *View > Show > File name extensions*. Windows hides them by default, so
  `invoice.pdf.exe` appears as `invoice.pdf`, and a program looks like a document. **Turn this on
  on every PC you support.**
- *Show hidden items*, in the same menu, when you need `AppData` and similar folders.

Windows 11's right-click menu is shorter than before; *Show more options*, or *Shift+right-click*,
brings back the full one that older instructions describe.

## Settings and Control Panel

Most things are in *Settings*, *Windows+I*. Some older ones are still only in **Control Panel**,
which opens by typing `control` in Start. When a guide names a Control Panel item that Settings does not
seem to have, that is why.

*Task Manager* is *Ctrl+Shift+Esc*, straight away, with no menu in between.
