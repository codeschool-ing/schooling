A processor has a small number of **cores**, and each core runs one thing at a time. This server
has four:

```
ana@server:~/office$ nproc
4
ana@server:~/office$ lscpu | grep -E '^(CPU\(s\)|Model name|Core\(s\) per socket)'
CPU(s):                                  4
Model name:                              Intel(R) Xeon(R) Processor @ 2.10GHz
Core(s) per socket:                      4
```

A normal office computer is running a hundred or more processes at any moment, and most of them are
asleep, like the two `sleep`s in the last section. The ones that are awake take turns. The part of
the kernel that decides whose turn it is is the **scheduler**:

Each turn is a few milliseconds. When a turn ends, the scheduler saves where the process was, picks
another one, and restores where *that* one was. It does this hundreds of times a second on every
core, which is why a song keeps playing while a spreadsheet recalculates, on a machine that can
really do only four things at once.

## What "slow" usually means

When there are more awake processes than cores, they wait in line. A little waiting is invisible.
A lot of it is the computer everybody calls slow, and there are two common reasons:

- **One process wants a core all the time**: a spreadsheet stuck recalculating, an antivirus scan, a
  browser tab running a heavy page. The list of processes shows it at the top, using close to one
  core's worth of processor.
- **Everything is waiting for something else**, usually the disk or memory (next section). The
  processor looks idle and the machine still crawls.

The first case has a one-line fix: find the process and stop it, or wait for it. The second one is
lesson 17's diagnosis.

## Priorities

Not every process is equal. The scheduler gives some more turns than others, so that the mouse
pointer keeps moving even when the machine is busy. You can lower a process's priority yourself:
`nice` on Linux and macOS, the *Details* tab of Task Manager on Windows. It is rarely needed, and it
is the right tool for a long job, like a backup, that should not get in anybody's way.
