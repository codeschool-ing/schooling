Um processador tem poucos **núcleos**, e cada núcleo roda uma coisa de cada vez. Este servidor tem
quatro:

```
ana@server:~/office$ nproc
4
ana@server:~/office$ lscpu | grep -E '^(CPU\(s\)|Model name|Core\(s\) per socket)'
CPU(s):                                  4
Model name:                              Intel(R) Xeon(R) Processor @ 2.10GHz
Core(s) per socket:                      4
```

Um computador comum de escritório está rodando cem processos ou mais a qualquer momento, e a maioria
deles está dormindo, como os dois `sleep` da seção anterior. Os que estão acordados se revezam. A
parte do kernel que decide de quem é a vez é o **escalonador** (*scheduler*):

Cada vez dura alguns milissegundos. Quando uma vez termina, o escalonador guarda onde o processo
estava, escolhe outro e restaura onde *aquele* estava. Ele faz isso centenas de vezes por segundo em
cada núcleo, e é por isso que uma música continua tocando enquanto uma planilha recalcula, numa
máquina que de fato só consegue fazer quatro coisas ao mesmo tempo.

## O que "lento" costuma querer dizer

Quando há mais processos acordados que núcleos, eles esperam na fila. Um pouco de espera é
invisível. Muita espera é o computador que todo mundo chama de lento, e há dois motivos comuns:

- **Um processo quer um núcleo o tempo todo**: uma planilha travada recalculando, uma varredura do
  antivírus, uma aba do navegador com uma página pesada. A lista de processos o mostra no topo,
  usando perto de um núcleo inteiro de processador.
- **Tudo está esperando outra coisa**, em geral o disco ou a memória (próxima seção). O processador
  parece ocioso e a máquina continua se arrastando.

O primeiro caso tem uma correção de uma linha: achar o processo e pará-lo, ou esperar por ele. O
segundo é o diagnóstico da aula 17.

## Prioridades

Nem todo processo é igual. O escalonador dá mais vezes a uns que a outros, para o ponteiro do mouse
continuar se mexendo mesmo com a máquina ocupada. Você mesmo pode baixar a prioridade de um
processo: `nice` no Linux e no macOS, a aba *Detalhes* do Gerenciador de Tarefas no Windows. Raramente
é preciso, e é a ferramenta certa para um trabalho longo, como um backup, que não deve atrapalhar
ninguém.
