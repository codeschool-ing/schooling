- *Before the logo*: nothing of the operating system has run. The cause is hardware or firmware, and
  the tools are the maker's built-in diagnostics, usually a key held at power-on (Apple Diagnostics is
  *D* on an Intel Mac, and the power button then *Command-D* on Apple silicon).
- *Before the system loads*: the boot loader cannot find or read the system. The tool is something
  that starts *from elsewhere*: WinRE, macOS Recovery from lesson 4, or lesson 3's live USB.
- *While it loads*: a driver or an update breaks the start. *Safe mode* starts the system with only
  the basic drivers and services, so if it works in safe mode, the cause is something safe mode left
  out.
- *After login*: the system runs, and it has been writing down what went wrong. The logs.
- *For one person only*: the machine is fine and one account is not. Lesson 15's per-user settings;
  try another account, or move that person's settings aside.

Most support calls are the last two, which is why this lesson spends most of its time on logs.
