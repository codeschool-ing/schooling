@ ng-model quiz easy #ex-r9z4495z
? In a template-driven form, what makes each control?
?? Num formulário template-driven, o que faz cada controle?

-- Um `FormControl` escrito na classe :: Isso é um formulário reativo.

-- O navegador, a partir do `name` do input :: O `name` é a chave; o `ngModel` faz o controle.
- `FormsModule`, once per form :: The module provides the directives; each `ngModel` makes one.
-- O `FormsModule`, uma vez por formulário :: O módulo fornece as diretivas; cada `ngModel` faz um.

-- Formulários template-driven não podem ter mais de um validador por campo :: Podem ter vários.

-- Arrays não são permitidos em formulários template-driven :: Um `@for` de `ngModel`s funciona, com nomes gerados.
