@ form-control quiz easy #ex-y6xm6y3w
? In a reactive form, where does the form's model live?
?? Num formulário reativo, onde fica o modelo do formulário?
- In the template, built from the `<input>` elements :: The template only points at the model.
-- No template, montado a partir dos elementos `<input>` :: O template só aponta para o modelo.
+ In the component's class :: Right. It can be read and typed without a template.
++ Na classe do componente :: Isso. Ele pode ser lido e tipado sem template.
- In the browser's own form state, read on submit :: Angular keeps its own model and the input in step with it.
-- No estado de formulário do próprio navegador, lido ao enviar :: O Angular mantém um modelo próprio e o input em sincronia com ele.
- In a service the form provides :: Nothing is provided; the controls are fields of the class.
-- Num serviço que o formulário fornece :: Nada é fornecido; os controles são campos da classe.

@ submitting quiz medium #ex-a5n2rp01

@ submitting quiz medium #ex-0dkr882v
