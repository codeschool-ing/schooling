@ tracking quiz hard #ex-hbak3cff
? A list of sessions is rebuilt from every server answer, with new objects each time. Which track key keeps what the user typed attached to the right session?
?? Uma lista de sessões é reconstruída a cada resposta do servidor, com objetos novos a cada vez. Que chave de track mantém o que o usuário digitou preso à sessão certa?

-- `track session`, o próprio objeto :: Toda resposta traz objetos novos, então nenhum é reconhecido e toda linha é desenhada de novo.

-- `track $index` :: Posições sobrevivem a uma reconstrução, mas um reordenamento move os dados por baixo delas.
+ `track session.id` :: Right. The id survives the rebuild and identifies the session.
++ `track session.id` :: Isso. O id sobrevive à reconstrução e identifica a sessão.
- `track session.date`, since a date is unique :: Two sessions can share a date, and a date can be edited.
-- `track session.date`, já que uma data é única :: Duas sessões podem ter a mesma data, e uma data pode ser editada.
