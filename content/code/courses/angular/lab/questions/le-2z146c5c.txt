# Lesson 20: directives

@ attribute quiz easy #ex-rxsb579b
? What is the difference between a directive and a component?
?? Qual é a diferença entre uma diretiva e um componente?
+ A directive has no template :: Right. It works on an element already there.
++ Uma diretiva não tem template :: Isso. Ela trabalha num elemento que já existe.
- A directive cannot have inputs :: `Highlight` has one.
-- Uma diretiva não pode ter inputs :: O `Highlight` tem um.
- A directive is only for forms :: `routerLink` is a directive too.
-- Uma diretiva é só para formulários :: O `routerLink` também é uma diretiva.
- A component cannot be put on an existing element :: A component draws its own template inside its element.
-- Um componente não pode ir num elemento existente :: Um componente desenha o próprio template dentro do elemento dele.
