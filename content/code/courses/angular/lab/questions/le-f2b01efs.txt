@ asking quiz easy #ex-hcwgc7r8
? What does `inject(Greeter)` in a component's field do?
?? O que o `inject(Greeter)` num campo de um componente faz?
- It creates a fresh `Greeter` with `new`, every time the field is read :: The field is set once, and the instance comes from an injector, not from `new` in the component.
-- Cria um `Greeter` novo com `new`, toda vez que o campo é lido :: O campo é definido uma vez, e a instância vem de um injetor, não de um `new` no componente.
+ It asks an injector for one and keeps the answer :: Right. The component never builds it.
++ Pede um a um injetor e guarda a resposta :: Isso. O componente nunca o constrói.
- It imports the file where `Greeter` is written :: The `import` line does that; `inject` asks for an instance at run time.
-- Importa o arquivo onde o `Greeter` está escrito :: A linha `import` faz isso; o `inject` pede uma instância em tempo de execução.
- It registers `Greeter` so other components can use it :: Registering is what a provider does; `inject` only asks.
-- Registra o `Greeter` para outros componentes poderem usar :: Registrar é o que um provider faz; o `inject` só pede.

@ tokens quiz medium #ex-92bf7xw0
? Why does the planner need `InjectionToken` for today, rather than `inject(Date)`?
?? Por que o planner precisa de `InjectionToken` para hoje, em vez de `inject(Date)`?
+ `inject(Date)` asks for the class, not a day :: Right. A token stands for a value that is not a class.
++ `inject(Date)` pede a classe, não um dia :: Isso. Um token representa um valor que não é uma classe.
- `Date` cannot be imported into an Angular component :: It is a global of the language; nothing stops you using it.
-- `Date` não pode ser importado num componente Angular :: É um global da linguagem; nada impede que você o use.
- An `InjectionToken` reads the clock more precisely :: It reads nothing; its factory calls `new Date()`, the same clock.
-- Um `InjectionToken` lê o relógio com mais precisão :: Ele não lê nada; a factory dele chama `new Date()`, o mesmo relógio.
- Tokens are the only things a test may override :: A test can override a class token just as well.
-- Tokens são as únicas coisas que um teste pode sobrepor :: Um teste pode sobrepor um token de classe do mesmo jeito.
