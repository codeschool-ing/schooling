@ switch-map quiz medium #ex-dmfnkggx
? What does `debounceTime(300)` do with the values of the query?
?? O que o `debounceTime(300)` faz com os valores da busca?
+ It passes one on only after 300 ms with no newer one :: Right. A burst of keys becomes one value.
++ Repassa um após 300 ms sem outro mais novo :: Isso. Uma rajada de teclas vira um valor.
- It delays every value by 300 ms and passes all of them :: That is `delay`; `debounceTime` drops the ones overtaken.
-- Atrasa todo valor em 300 ms e repassa todos :: Isso é o `delay`; o `debounceTime` descarta os ultrapassados.
- It cancels any request slower than 300 ms :: It acts on the values before any request exists.
-- Cancela qualquer pedido mais lento que 300 ms :: Ele age sobre os valores antes de existir pedido.
- It lets one value through every 300 ms :: That is closer to `throttleTime`.
-- Deixa passar um valor a cada 300 ms :: Isso está mais perto do `throttleTime`.
