@ a-service quiz medium #ex-nnjx2cnw
? Why does the store write `this.data.hasValue() ? this.data.value().courses : []` rather than `this.data.value()?.courses ?? []`?
?? Por que o store escreve `this.data.hasValue() ? this.data.value().courses : []` em vez de `this.data.value()?.courses ?? []`?
- `?.` does not work inside a `computed` :: It works anywhere a TypeScript expression does.
-- O `?.` não funciona dentro de um `computed` :: Funciona em qualquer lugar onde uma expressão TypeScript funciona.
+ `value()` throws in the error state :: Right. The check comes first, so the computed never throws.
++ `value()` lança erro no estado de erro :: Isso. A conferência vem antes, então o computed nunca lança.
- `hasValue()` starts the request if it has not started :: It only reads the state; the resource started on its own.
-- `hasValue()` inicia o pedido se ele não tiver começado :: Ele só lê o estado; o resource começou sozinho.
- `hasValue()` is faster than reading the value :: Speed is not the reason.
-- `hasValue()` é mais rápido que ler o valor :: Velocidade não é o motivo.

@ scope quiz medium #ex-7c7jm6d1
? How can you tell, reading the code, whether a service is really shared?
?? Como dá para saber, lendo o código, se um serviço é mesmo compartilhado?
- By the word `Store` or `Service` in its name :: Names say nothing about where it is provided.
-- Pela palavra `Store` ou `Service` no nome :: Nomes não dizem nada sobre onde ele é fornecido.
- By `@Injectable()` on the class :: That only lets Angular build it.
-- Pelo `@Injectable()` na classe :: Isso só deixa o Angular construí-lo.
- By whether its methods change signals :: That is about state, not scope.
-- Por os métodos dele mudarem signals ou não :: Isso é sobre estado, não escopo.
+ By `providedIn` and every `providers:` list that names it :: Right. Whoever writes the provider decides the scope.
++ Pelo `providedIn` e por toda lista `providers:` que o cita :: Isso. Quem escreve o provider decide o escopo.
