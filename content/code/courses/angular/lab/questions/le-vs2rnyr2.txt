? You want to know whether your change broke anything, and then see it in a browser. Which pair of commands, in which order?
?? Você quer saber se a sua mudança quebrou algo, e depois vê-la num navegador. Que par de comandos, em que ordem?
- `ng build`, then `ng update` :: Neither tells you whether the behaviour broke, and `ng update` changes versions.
-- `ng build`, depois `ng update` :: Nenhum dos dois diz se o comportamento quebrou, e o `ng update` muda versões.
- `ng generate`, then `ng serve` :: `ng generate` writes new files; it checks nothing.
-- `ng generate`, depois `ng serve` :: O `ng generate` escreve arquivos novos; ele não confere nada.
+ `ng test`, then `ng serve` :: Right. The tests answer the first question, and the dev server the second.
++ `ng test`, depois `ng serve` :: Isso. Os testes respondem a primeira pergunta, e o servidor de desenvolvimento a segunda.
- `ng serve`, then `ng new` :: `ng new` starts a different project.
-- `ng serve`, depois `ng new` :: O `ng new` começa outro projeto.
