**A file format is mostly a decision about which values sit next to each other on the disk.** The
common picture is different: a format is a way of spelling a table, commas in one, braces in
another, and choosing between them is a matter of taste. Spelling matters less than it looks. What
decides whether a format is fast for a job is its **layout**, and there are only two families of it.

A **row-oriented** format writes one record whole, every field of it, and then the next record.
CSV, JSON Lines and Avro are row formats. A **column-oriented** format, also called columnar, writes
every value of one column, then every value of the next. Parquet and ORC are columnar.

A disk, an SSD and a network all hand over bytes in runs, and a reader pays for every byte it has
to pass over. So each layout makes one kind of work cheap and the opposite kind dear:

| the work | row-oriented | column-oriented |
|---|---|---|
| append one ride the moment it ends | one write at the end of the file | a value added to seven separate runs |
| read one whole ride back | one contiguous read | seven reads, one per column, put back together |
| average `minutes` over a month of rides | every byte of every ride is read | one run is read, the rest is skipped |
| shrink the file | neighbours are unlike: an id, a station, a time | neighbours are alike: twelve stations repeated |

The left column is how the app works. It writes one ride when the bicycle is docked and reads one
customer's history when they open it. The right column is how Marta's questions work: one or two
columns, over every ride there ever was. That is why the app's database, which lesson 4 calls
OLTP, keeps rows, and why the files a data team keeps for analysis are usually columnar.

## Seeing both on your own machine

The rest of this lesson writes the same rides in all five formats, so it starts with a program that
makes them. It assumes the lab from lesson 1: `~/roda` with its environment active. Make this
lesson's directory and work in it:

```sh
mkdir -p ~/roda/formats
cd ~/roda/formats
```

Save it as `formats/rides.py`. Every other program in this lesson imports `make` from it.

Read down the `start_station` line of the second half: three short codes from a list of twelve,

different values, which is exactly the kind of run a columnar file can shrink to almost nothing.
