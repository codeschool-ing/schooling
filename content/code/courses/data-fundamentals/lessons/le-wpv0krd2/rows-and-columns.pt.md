**Um formato de arquivo é, antes de tudo, uma decisão sobre quais valores ficam lado a lado no
disco.** A imagem comum é outra: um formato seria um jeito de soletrar uma tabela, com vírgulas num,
chaves no outro, e escolher entre eles seria questão de gosto. A grafia importa menos do que parece.
O que decide se um formato é rápido para um trabalho é o seu **arranjo**, e só existem duas famílias
dele.

Um formato **orientado a linhas** grava um registro inteiro, todos os campos dele, e depois o
registro seguinte. CSV, JSON Lines e Avro são formatos de linhas. Um formato **orientado a colunas**,
também chamado de colunar, grava todos os valores de uma coluna, depois todos os valores da
seguinte. Parquet e ORC são colunares.

Um disco, um SSD e uma rede entregam bytes em sequências, e quem lê paga por cada byte que precisa
atravessar. Por isso cada arranjo deixa um tipo de trabalho barato e o tipo oposto caro:

| o trabalho | orientado a linhas | orientado a colunas |
|---|---|---|
| acrescentar uma viagem assim que ela termina | uma gravação no fim do arquivo | um valor acrescentado a sete sequências separadas |
| ler uma viagem inteira de volta | uma leitura contínua | sete leituras, uma por coluna, remontadas |
| média de `minutes` num mês de viagens | todo byte de toda viagem é lido | uma sequência é lida, o resto é pulado |
| encolher o arquivo | vizinhos diferentes: um id, uma estação, um horário | vizinhos parecidos: doze estações repetidas |

A coluna da esquerda é como o aplicativo trabalha. Ele grava uma viagem quando a bicicleta é
devolvida à doca e lê o histórico de um cliente quando o cliente o abre. A coluna da direita é como
as perguntas de Marta trabalham: uma ou duas colunas, sobre todas as viagens que já existiram. É por
isso que o banco do aplicativo, que a aula 4 chama de OLTP, guarda linhas, e que os arquivos que um
time de dados guarda para análise costumam ser colunares.

## Vendo os dois na sua máquina

O resto desta aula grava as mesmas viagens nos cinco formatos, então ela começa com um programa que
as fabrica. Ela supõe o laboratório da aula 1: `~/roda` com o ambiente ativo. Crie o diretório desta
aula e trabalhe nele:

```sh
mkdir -p ~/roda/formats
cd ~/roda/formats
```

Salve-o como `formats/rides.py`. Todos os outros programas desta aula importam `make` dele.
