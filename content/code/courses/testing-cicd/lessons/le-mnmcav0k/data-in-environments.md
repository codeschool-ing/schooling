title: Data in each environment
version: 1

The code is the same in every environment and the configuration differs by design. **Data is the
third thing an environment holds, and the hardest to get right**, because the realistic choice and the
lawful choice pull in opposite directions.

## Production's data stays in production

Lesson 3 section 11 set the rule for tests, and it applies to environments with more force: staging is
usually reached by more people, through weaker controls, than production. A copy of customers' data
there is a copy of personal data with less protection, and under the LGPD it is processing that needs
a purpose and a legal basis. "We needed realistic data for staging" is a reason that has led to real
leaks, because staging databases are the ones nobody watches.

## What goes in instead

| need | answer |
|---|---|
| tables with something in them | seed data generated by the same factories the tests use (lesson 3) |
| realistic volume, for performance | generated data at production's scale, shaped by its statistics, not its rows |
| a bug that only a real record shows | the shape of the record reproduced by hand, as a factory case |
| reviewing a feature with real content | content created for the purpose, by the team or the business |

A seeding script that runs on every deploy to a non-production environment makes the data part of the
environment's definition, like its configuration. That also makes preview environments possible:
each one starts with the same known data.

## Configuration that points at data

The variables of section 03 decide which data an environment touches: a database address, a bucket
name, a carrier account. **The most damaging configuration mistake is a non-production environment
pointing at production's data**, a staging service writing to the production database because one
line was copied from the wrong file. Two habits guard against it: production's credentials exist only
in production's configuration, and production's data services refuse connections from anywhere else.
Lesson 9 makes the first of those concrete.
