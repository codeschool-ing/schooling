A confidence interval and a two-sided test are two views of one calculation. For a 95% interval and a test at α = 0.05:

> The null value lies **outside** the 95% interval exactly when the two-sided p-value is **below 0.05**.

## Horta's two examples

**The routing system.** The 25 deliveries give a 95% interval for the mean of **36.62 to 41.18 minutes**. The null value, 40, is inside it, and the two-sided p-value is 0.33. Both say the same thing: the data is consistent with no change.

**The filling machine.** The 15 bags give a 95% interval of **1002.26 to 1006.94 g**. The null value, 1000, is outside it, and the two-sided p-value is 0.0009. Both say the machine is off target.

## Why the interval is usually more useful

The p-value answers one question: is the data consistent with one particular value? The interval answers it for **every** value at once.

The routing interval says more than "not significant". It says the true mean could be anywhere from 36.62 to 41.18 minutes. That includes no change at all, and it includes an improvement of more than three minutes. A manager reading only "p = 0.33" might conclude the system is useless; a manager reading the interval sees that the experiment simply could not tell, and that a larger trial might be worth running.

The filling interval says more than "significant". It says the overfill is between 2.3 and 6.9 g per bag, which is what Horta needs to estimate how much rice is being given away.

## The interval answers "how much"

This is the main reason statistical reporting has moved towards intervals. A test says **whether** an effect is distinguishable from zero. An interval says **how big** it might be, which is almost always the question a decision depends on. Lesson 22 builds on exactly this: a significant result can be too small to matter, and only the interval shows it.
