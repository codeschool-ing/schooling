## A inclinação

A inclinação é **a mudança na resposta prevista para uma unidade a mais do preditor**. Para as entregas, 2,48 minutos por quilômetro. Quatro quilômetros a mais querem dizer cerca de 4 × 2,48 = 9,9 minutos a mais, seja qual for a distância de partida: é isso que uma reta supõe.

A inclinação carrega as unidades das duas variáveis, minutos por quilômetro, e muda com elas: medida em metros, seria 0,00248 minuto por metro. Diferente do *r*, ela não é um número puro. Essa é a força dela. *r* = 0,91 diz que a relação é estreita; *b* = 2,48 diz quanto cada quilômetro **custa**.

## A inclinação é mais que acaso?

A inclinação estimada a partir de 120 entregas é uma estatística e, como uma média, tem erro padrão. Para as entregas ele é **0,101** minuto por quilômetro. O teste de se a inclinação verdadeira é zero usa t = 2,48 ÷ 0,101 = **24,5**, com n − 2 = 118 graus de liberdade, o mesmo t do teste do *r* na aula 17. Um intervalo de 95% para a inclinação é mais ou menos 2,48 ± 2 × 0,101, de **2,28 a 2,68** minutos por quilômetro.

## O intercepto

O intercepto é a resposta prevista quando o preditor é **zero**. Para as entregas, 25,0 minutos a zero quilômetro. Se isso quer dizer algo depende de zero ser um valor sensato. Aqui mais ou menos quer: uns 25 minutos vão em separar, embalar e entregar, seja qual for a distância.

Muitas vezes não quer. Uma regressão do peso pela altura tem intercepto numa altura zero, que não descreve ninguém. Para os doze pedidos, o intercepto é **−R$ 8,88**, a cesta prevista para um pedido sem itens, que não é um preço que alguém pagou. O intercepto continua necessário para posicionar a reta; só não deve ser lido sozinho quando o zero está fora dos dados.
