Um teste começa com duas afirmações concorrentes sobre a população.

A **hipótese nula**, escrita **H₀**, é a afirmação de nenhum efeito, nenhuma diferença, nenhuma mudança. É a
explicação sem graça, e é a que o teste supõe.

A **hipótese alternativa**, escrita **H₁** ou Hₐ, é o que você concluiria se a nula fosse rejeitada: há um
efeito, uma diferença, uma mudança.

## O sistema de rotas da Horta

Antes do novo sistema, as entregas levavam em média **40 minutos**. A pergunta é se agora estão mais
rápidas. Com μ o tempo médio verdadeiro de entrega no novo sistema:

- H₀: μ = 40. O novo sistema não faz diferença.
- H₁: μ < 40. O novo sistema deixa as entregas mais rápidas.

## Três regras para escrevê-las

**A nula contém o sinal de igual.** Ela nomeia um valor preciso, porque o teste precisa de uma previsão
precisa para comparar com os dados. "μ = 40" dá uma; "μ < 40" não dá.

**As duas falam da população, não da amostra.** Usam μ, nunca *x̄*. A média amostral é conhecida — é 38,9 —,
então uma hipótese sobre ela não teria sentido. As hipóteses tratam daquilo de que a amostra é evidência.

**Elas são escritas antes de ver os dados.** A pergunta vem primeiro, e os dados a respondem. Escrever a
hipótese depois de olhar os dados, para encaixar o padrão que apareceu, transforma um teste numa descrição
da amostra fantasiada de descoberta. A aula 14 mostra quanto isso custa.

## Mais exemplos

| pergunta | H₀ | H₁ |
|---|---|---|
| A envasadora está no alvo de 1000 g? | μ = 1000 | μ ≠ 1000 |
| A nova página de pagamento converte mais visitantes? | *p*nova = *p*antiga | *p*nova > *p*antiga |
| Dois bairros têm tempos de entrega diferentes? | μ₁ = μ₂ | μ₁ ≠ μ₂ |
| A satisfação está abaixo da meta de 70%? | *p* = 0,70 | *p* < 0,70 |

Em cada linha a nula é a afirmação de que nada interessante está acontecendo, e o teste pergunta se os dados
podem ser conciliados com ela.
