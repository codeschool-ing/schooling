title: The null and the alternative

A test begins with two competing statements about the population.

The **null hypothesis**, written **H₀**, is the statement of no effect, no difference, no change. It is the boring explanation, and it is the one the test assumes.

The **alternative hypothesis**, written **H₁** or Hₐ, is what you would conclude if the null were rejected: there is an effect, a difference, a change.

## Horta's routing system

Before the new system, deliveries averaged **40 minutes**. The question is whether they are faster now. With μ the true mean delivery time under the new system:

- H₀: μ = 40. The new system makes no difference.
- H₁: μ < 40. The new system makes deliveries faster.

## Three rules for writing them

**The null contains the equals sign.** It names one precise value, because the test needs a precise prediction to compare the data with. "μ = 40" gives one; "μ < 40" does not.

**Both are about the population, not the sample.** They use μ, never *x̄*. The sample mean is known — it is 38.9 — so a hypothesis about it would be pointless. The hypotheses are about what the sample is evidence of.

**They are written before the data is seen.** The question comes first and the data answers it. Writing the hypothesis after looking at the data, to fit whatever pattern turned up, turns a test into a description of the sample dressed up as a discovery. Lesson 14 shows what that costs.

## More examples

| question | H₀ | H₁ |
|---|---|---|
| Is the filling machine on its 1000 g target? | μ = 1000 | μ ≠ 1000 |
| Does the new checkout page convert more visitors? | *p*new = *p*old | *p*new > *p*old |
| Do two neighbourhoods have different delivery times? | μ₁ = μ₂ | μ₁ ≠ μ₂ |
| Is satisfaction below the 70% target? | *p* = 0.70 | *p* < 0.70 |

In each row the null is the statement that nothing interesting is going on, and the test asks whether the data can be reconciled with it.
