Uma rede é coisa demais para caber na cabeça de uma vez. O **modelo OSI** (*Open Systems
Interconnection*, publicado pela ISO em 1984) divide a rede em sete camadas. Cada camada faz um
trabalho, usa a camada de baixo para fazê-lo e oferece um serviço à camada de cima.

Leia de baixo para cima. A camada 1 leva sinais por um cabo ou pelo ar. A camada 2 usa esses sinais
para entregar um quadro a um dispositivo no mesmo enlace. A camada 3 leva um pacote entre redes,
roteador a roteador, até a máquina certa. A camada 4 entrega os dados ao programa certo nessa máquina
e, no caso do TCP, garante que tudo chegue. As camadas 5 a 7 tratam do que os programas dizem uns aos
outros.

Duas consequências tornam o modelo útil, e não só acadêmico:

- **Quando uma camada falha, tudo acima dela falha também**, diga o que disser a mensagem de erro na
  tela. Um navegador dizendo que o site "não pode ser acessado" pode estar olhando para um cabo
  desconectado.
- Cada camada tem seu próprio tipo de endereço. Um endereço MAC na camada 2, um endereço IP na camada
  3, uma porta na camada 4, um nome como `www.example.com` na camada 7. Perguntar de qual endereço uma
  mensagem trata diz em que camada você está.

Os protocolos para os quais o modelo foi escrito perderam para o TCP/IP, assunto da aula 2, e o
modelo continua sendo ensinado por causa da primeira consequência. "A internet caiu" vira perguntas
que dá para responder em ordem: há enlace, há endereço, chega ao roteador, chega ao servidor, o
serviço está escutando, o nome resolve. Esta aula faz cada uma numa rede de verdade.

## O laboratório

Todo comando deste curso rodou num laboratório montado para ele: o escritório da Example Ltd, com um
laptop, um servidor e um roteador; um provedor de internet; e uma pequena internet com seus próprios
servidores de DNS e um servidor web para `www.example.com`. É um só computador Linux fazendo o papel
de cada máquina do desenho, e por isso todos os endereços são dos reservados para documentação, e uma
ida e volta pela sua "internet" leva uma fração de milissegundo. **Um prompt que diz `ana@laptop`
rodou no laptop, `ana@www` no servidor web**, e assim por diante.
