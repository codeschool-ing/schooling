**A cell that holds two values has to be cut before either can be used.** The `Item` column says
`SUL1K - Sul de Minas 1 kg`: a product code and a name, joined by a space, a hyphen and a space.
`Sales` and `Products` both identify a product by its code alone, so the code has to come out, and
the way to cut it is to find the separator and take what is on one side of it.

## Positions: LEFT, RIGHT, MID and FIND

Excel numbers the characters of a text from 1. Three functions take a piece by position:

- `LEFT(text, n)` takes the first *n* characters;
- `RIGHT(text, n)` takes the last *n*;
- `MID(text, start, n)` takes *n* characters beginning at position *start*.

The codes are of different lengths, five characters in `SUL1K` and six in `SUL250`, so no fixed *n*
works for all of them. What every row has in common is the separator, and `FIND` answers where it
starts:

```localised
=FIND(" - ", D2)
```

answers **6**: the space before the hyphen is the sixth character of `SUL1K - Sul de Minas 1 kg`. The
code is everything before it, which is one character fewer:

In **K1** type `Product`, and in **K2**:

```localised
=UPPER(LEFT(D2, FIND(" - ", D2)-1))
```

Fill it down to K13. Each row finds its own separator, so `DEC250` and `MOG250` come out whole,
and `UPPER` repairs row 4, whose code arrived as `cer1k`. Row 4 now says `CER1K`, which is the
spelling `Products` uses.

The name is the other side. It starts three characters after the separator does, and `MID` with a
generous length takes the rest of the text, however long:

```localised
=MID(D2, FIND(" - ", D2)+3, 100)
```

answers **Sul de Minas 1 kg**. The name is not needed here, since `Products` already has it, but
the pattern is the one to remember: find the separator, then measure from it.

`FIND` is case-sensitive and stops with `#VALUE!` when the text is not there at all. A row without
the separator would show that error, and you would want it to: it is a row that does not fit the
pattern, and a formula that quietly made something up would hide it. `SEARCH` does the same job and
ignores case.

**Microsoft 365 and Excel 2024 have a shorter way.** `TEXTBEFORE(D2, " - ")` returns everything
before the separator, `SUL1K`, and `TEXTAFTER(D2, " - ")` everything after it, with no counting.
They are not in Excel 2021 or earlier, which is why the course teaches the `FIND` pattern, which
works in every version.

## Without a formula

Two commands do the same cut by hand. **Data › Text to Columns**, with **Delimited** and the hyphen
as the separator, splits the column into two in place. **Data › Flash Fill**, or **Ctrl+E**, watches
you type the first code or two in a new column and fills in the rest by guessing the pattern.

Both are quick, and both leave values rather than formulas. When next month's export arrives, a
formula column fills down over it, while a Text to Columns split or a Flash Fill has to be done
again. Flash Fill's guess also has to be checked again, because it can pick the wrong pattern from
too few examples. For a one-off list, use them; for data that comes back, write the formula.

## Joining: &

The opposite operation is `&`, which glues texts together, as you did with operators and dates in
lesson 5. A label for the first order, in any empty cell:
