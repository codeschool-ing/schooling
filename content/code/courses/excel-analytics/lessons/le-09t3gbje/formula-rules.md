title: Formula rules, and the dollar sign that decides which cells
version: 1

**A formula rule colours a cell when a formula answers `TRUE` for it, and the formula is written
once, for the top-left cell of the range, then read for every other cell as if it had been
copied there.** That is the same movement lesson 2 taught for filling a formula, and the same
dollar signs decide what moves. Getting them right is the whole skill.

## Colouring every wholesale sale

Select the data of the `Sales` table, A2:H109: click A2, then Shift+click H109. Choose
**Home › Conditional Formatting › New Rule**, pick **Use a formula to determine which cells to
format**, and type:

```localised
=$G2="Wholesale"
```

Click **Format**, choose a fill on the **Fill** tab, and **OK** twice. Every row whose channel is
`Wholesale` is coloured from A to H, and a formula confirms how many rows that is:

```localised
=COUNTIF(Sales[Channel], "Wholesale")
```

**38**. Read the rule from the point of view of one cell. For C5, Excel takes the formula written
for A2 and moves it the way a copy from A2 to C5 would move it: the row moves by 3, so `2`
becomes `5`, and the column would move by 2, except that `$G` is fixed. C5 therefore asks
`=$G5="Wholesale"`, the channel of its own row, and so does every cell of row 5.

As with data validation in lesson 8, the rule box takes ordinary addresses, so write `$G2` rather
than a structured reference such as `[@Channel]`.

The figure shows what the same rule does with the dollar sign in three places, on the 108 rows:

- `=$G2="Wholesale"` colours **304** cells: 38 rows, all eight columns of each.
- `=G2="Wholesale"`, with no dollar sign, colours **38** cells, all of them in column A. In column
  B the formula has moved one column right and asks about H, the revenue, which is never the word
  `Wholesale`; in column C it asks about I, and so on. Only column A still looks at `Channel`.
- `=$G$2="Wholesale"` colours all **864** cells. Every cell asks about G2, the channel of sale

  be coloured at all, and neither mistake shows an error.

The rule of thumb: **fix the column the test reads, and leave the row free**, so each row tests
itself.

## A threshold somebody can change

A number typed inside a rule can only be changed by opening the rule. Put it in a cell instead,
and the colouring follows the cell. Type `1500` in an empty cell to the right of the table, click
it, type `Threshold` in the **Name Box** at the left of the formula bar and press Enter: the cell
now has the name `Threshold`, as in lesson 2. Then add a second rule to A2:H109:

```localised
=$H2>=Threshold
```

With a different fill, it colours the **9** sales of R$ 1,500 or more. Type `1000` in the
`Threshold` cell and **18** are coloured, the same 18 the ready-made rule found in section 02,
because no sale is exactly R$ 1,000. The rule never changed. Whoever reads the sheet can move the
line without knowing where rules are kept.

## The promise from lesson 8: a row with a gap

Validation cannot make a cell compulsory. A formula rule can at least make an empty one visible.
On the `New sales` sheet, select A2:G2 of the `NewSales` table and add this rule, with a strong
fill:

```localised
=AND($A2<>"", A2="")
```

`$A2` is fixed to column A, so every cell of the row asks whether the row has a sale code. `A2`
has no dollar sign, so each cell also asks whether it is itself empty. A row that has been started
and not finished shows its gaps, and an untouched row shows nothing. Like the validation rules,
the format spreads to every row the table grows by.
