**From Folder reads every file in a folder as rows of one query, so next month's export is
added by saving it into the folder and pressing Refresh All.** No query changes, no rows are
copied, and a file that arrives late is picked up by the next refresh like any other.

## Combining the folder

Go to **Data › Get Data › From File › From Folder** and choose the `web` folder. Excel lists what
it found, one row per file, with columns such as `Name`, `Extension` and `Date modified`. Nothing
has been read from inside the files yet: this is a list of files, and its first column, `Content`,
holds each file unopened.

At the bottom, open **Combine** and choose **Combine & Transform Data**. A **Combine Files**
dialog shows the first file as a sample, with the same three boxes section 03 used. Check that the
delimiter is **Comma**, choose **Do not detect data types**, and click **OK**.

## What Excel built for you

The **Queries & Connections** pane now shows more than one query. Beside `WebOrders` there is a
group, usually called **Transform File from web**, holding a few helper queries: a sample file, a
parameter, and a function called **Transform File**.

They exist because the combining is done in two halves. **Transform Sample File** holds the steps
applied to each file on its own: read the text, split at the commas, promote the header. The
function is a copy of those steps that can be pointed at any file. The main query lists the
folder and calls the function once per file, then stacks what comes back.

So there are two places to change a step, and they mean different things. A step in **Transform
Sample File** happens to each file before stacking. A step in `WebOrders` happens to all the rows
together afterwards. A change that every file needs on its own, such as skipping a line the
platform writes above the header, goes in the sample; anything else goes in the main query.

## What breaks it

**A file of another shape in the folder.** The steps of the sample are applied to every file, so
the courier's invoice saved into `web` would be split at its commas and stacked under the orders
as nonsense. That is why section 03 saved it one folder up. As a guard, open `WebOrders`, click
its first step, `Source`, and filter the `Name` column with **Text Filters › Begins With** and
`web-`. Excel asks before inserting a step in the middle of the list; say yes. A stray file saved
into the folder later is then ignored.

**A header that changes.** If the platform one day calls the column `Quantity` instead of `Qty`,
that month's rows arrive with the quantity in a column the query has never heard of. Lesson 14
section 07 shows how that surfaces as an error, and what to do.
