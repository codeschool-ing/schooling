O FastAPI não tem sistema de permissões: **uma guarda é uma dependência que levanta 403**, e a rota a
pede do jeito que pediu a session. O agenda-api ganha as mesmas duas regras, com um **papel** no
lugar das permissões do Django. Em `app/models.py`, o `Event` ganha um organizador e o `User` uma
marca de admin:

```python
# app/models.py
from datetime import datetime

from sqlalchemy import DateTime, ForeignKey, String, Text, UniqueConstraint, false, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship


class Base(DeclarativeBase):
    pass


class Event(Base):
    __tablename__ = "events"

    id: Mapped[int] = mapped_column(primary_key=True)
    slug: Mapped[str] = mapped_column(String(50), unique=True)
    title: Mapped[str] = mapped_column(String(200))
    starts_at: Mapped[datetime] = mapped_column(DateTime(timezone=True))
    venue: Mapped[str] = mapped_column(String(200))
    capacity: Mapped[int]
    description: Mapped[str] = mapped_column(Text, default="")
    organiser_id: Mapped[int | None] = mapped_column(
        ForeignKey("users.id", name="events_organiser_id_fkey")
    )

    registrations: Mapped[list["Registration"]] = relationship(
        back_populates="event", order_by="Registration.id"
    )

    @property
    def taken(self) -> int:
        return len(self.registrations)


class Registration(Base):
    __tablename__ = "registrations"
    __table_args__ = (UniqueConstraint("event_id", "email"),)

    id: Mapped[int] = mapped_column(primary_key=True)
    event_id: Mapped[int] = mapped_column(ForeignKey("events.id"))
    name: Mapped[str] = mapped_column(String(100))
    email: Mapped[str] = mapped_column(String(254))
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now()
    )

    event: Mapped[Event] = relationship(back_populates="registrations")


class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    username: Mapped[str] = mapped_column(String(150), unique=True)
    password_hash: Mapped[str] = mapped_column(String(255))
    is_admin: Mapped[bool] = mapped_column(default=False, server_default=false())
```

A chave estrangeira tem **nome**. Sem um, o autogenerate escreve `None` como nome da restrição nos
dois sentidos, e o PostgreSQL inventa um quando o upgrade roda; o downgrade então pede para apagar uma
restrição chamada `None` e falha, que é o caso da restrição sem nome da lista da aula 10. O
`server_default=false()` dá um valor às linhas existentes, então a coluna nova pode ser `NOT NULL`:

## As guardas

Salve o `app/guards.py`:

```schooling-example
{"language": "python", "file": "app/guards.py", "parts": [{"code": "# app/guards.py\nfrom typing import Annotated\n\nfrom fastapi import Depends, HTTPException, status\n\nfrom .dependencies import EventDep\nfrom .models import Event, User\nfrom .security import CurrentUser\n\n\n", "note": "Guardas são dependências construídas sobre o `CurrentUser`, então uma requisição sem token é recusada com 401 antes de qualquer uma delas rodar."}, {"code": "def admin(user: CurrentUser) -> User:\n    if not user.is_admin:\n        raise HTTPException(status.HTTP_403_FORBIDDEN, \"Only an admin may do this.\")\n    return user\n\n\nAdminUser = Annotated[User, Depends(admin)]\n\n\n", "note": "**Um papel**: uma coluna no usuário, conferida por uma função que toda rota só de admin pede."}, {"code": "def editable_event(event: EventDep, user: CurrentUser) -> Event:\n    if not (user.is_admin or event.organiser_id == user.id):\n        raise HTTPException(status.HTTP_403_FORBIDDEN, \"Only this event's organiser may change it.\")\n    return event\n\n\nEditableEvent = Annotated[Event, Depends(editable_event)]\n", "note": "**Posse**: o evento do caminho, o usuário do token, e a regra que os junta."}]}
```

Uma atualização parcial precisa de um schema em que todo campo é opcional. Acrescente-o ao
`app/schemas.py`, antes do `RegistrationIn`:

```python
class EventPatch(BaseModel):
    title: str | None = Field(default=None, min_length=1, max_length=200)
    capacity: int | None = Field(default=None, ge=1, le=1000)
    description: str | None = None
```

E uma rota que o usa, no `app/main.py` depois do `create_event`:

```python
@app.patch("/events/{slug}", response_model=EventOut, tags=["events"])
def update_event(changes: EventPatch, event: EditableEvent, session: SessionDep):
    for field, value in changes.model_dump(exclude_unset=True).items():
        setattr(event, field, value)
    session.commit()
    return event
```

O `exclude_unset=True` guarda só os campos que o cliente mandou, então um PATCH de `{"capacity": 30}`
deixa o título em paz. No mesmo arquivo, importe `AdminUser` e `EditableEvent` de `.guards` e
`EventPatch` de `.schemas`; o `create_event` recebe `user: AdminUser` e registra o organizador:


## As mesmas portas

O `doors.py` do agenda-api muda o endereço, o formulário de login e o cabeçalho. Salve em
`~/agenda-api`:

```python
# doors.py
import httpx2

API = "http://127.0.0.1:8001/"
PASSWORDS = {"carla": "k7-meadow-harbour-23", "bruno": "m4-orchard-copper-17", "ana": "x9-river-lantern-42"}
DOORS = [
    ("read Django Night", "GET", "events/django-night"),
    ("change Testing dojo", "PATCH", "events/testing-dojo"),
    ("change Async workshop", "PATCH", "events/async-workshop"),
    ("create an event", "POST", "events"),
]


def headers(user):
    if user is None:
        return {}
    answer = httpx2.post(API + "token", data={"username": user, "password": PASSWORDS[user]})
    return {"Authorization": "Bearer " + answer.json()["access_token"]}


people = [None, "carla", "bruno", "ana"]
sent = {user: headers(user) for user in people}
print(f"{'':24}" + "".join(f"{user or 'anonymous':>11}" for user in people))
for name, method, path in DOORS:
    body = None if method == "GET" else {}
    codes = [httpx2.request(method, API + path, json=body, headers=sent[user]).status_code for user in people]
    print(f"{name:24}" + "".join(f"{code:>11}" for code in codes))
```

serializer do DRF respondeu 400. O que o Bruno vê:

A guarda recusou o evento da ana e deixou passar o dele, com a capacidade nova na resposta. Onde o DRF
tem dois métodos, o FastAPI tem as dependências que uma rota declarar, e **uma rota que esquece de
declarar uma está aberta**: nada confere se toda escrita tem guarda. A aula 14 escreve a tabela de
portas como teste, para que uma guarda esquecida quebre o build em vez de chegar à produção.
