A família inteira se chama **vSphere**, e as palavras que você vai ouvir dos administradores dela são
estas:

| palavra | o que é |
|---|---|
| host | um servidor rodando ESXi |
| datastore | onde moram os discos: VMFS num disco do host ou compartilhado, ou um compartilhamento NFS |
| vSwitch, port group | o switch virtual do host, e um grupo com nome das portas dele, com uma VLAN |
| vMotion | mover uma VM ligada para outro host, o que precisa do vCenter |
| HA | religar as VMs de um host que caiu nos outros |
| VMware Tools | o agente do convidado, aula 3 |
