title: Three answers to one question
version: 1

A guest's card is plugged into a virtual switch on the host. What that switch is joined to answers
three questions at once: **where the guest's address comes from, what it can reach, and who can reach
it.**

| mode | address from | the guest reaches | reaches the guest |
|---|---|---|---|
| **NAT** | the hypervisor's own DHCP | anything the host reaches | nobody, unless a port is forwarded |
| **bridged** | the real network's DHCP | the real network, like any computer | anyone on the real network |
| **host-only**, isolated | the hypervisor's DHCP | the host and other guests on it | the host and those guests |
| **internal**, private | nobody's, unless you set one | other guests on it | only those guests |

The names differ by product, and this table is the translation:

| | NAT | bridged | host-only | internal |
|---|---|---|---|---|
| libvirt | `default` network | `forward mode="bridge"` | a network with no `forward` | a network with no address |
| VirtualBox | NAT, NAT Network | Bridged Adapter | Host-only Adapter | Internal Network |
| VMware Workstation | VMnet8 | VMnet0 | VMnet1 | a LAN segment |
| Hyper-V | Default Switch | External | Internal | Private |
