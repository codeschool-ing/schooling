a visual connection with something else on it**. On a slide, that connection is almost always an edge
or a centre line shared with another element.

## The invisible grid

On the left, the title starts at one distance from the edge, the chart at another and the source note at a
third. Each placement is reasonable on its own, and together they look careless. On the right, **the title,
the chart's axis and the note all start on the same vertical line**, and the chart and the annotation share a
top edge. Nothing new was added; things were moved a few millimetres. The slide looks deliberate, and a
deliberate-looking slide is trusted a little more before anybody reads it.

Most slide tools draw guides when an element lines up with another; turn them on, and use the same left
margin on every slide.

## Left beats centred for text

Centred text is the default in many templates, and it is the weakest alignment for anything longer than a
title. **A centred block has a ragged edge on both sides**, so the eye has to find the start of every line
afresh. Left-aligned text gives the eye one strong edge to return to. Keep centring for a single short
line, such as a big number on its own, where there is no next line to find.

## Alignment across slides

The grid should be the same on every slide: the title at the same height and the same left edge, the chart
area in the same place. When it moves between slides, the image visibly jumps as you advance, and the
room spends a moment re-finding the title each time. That is the bridge to the next principle, which is
about everything that should look the same throughout a deck.
