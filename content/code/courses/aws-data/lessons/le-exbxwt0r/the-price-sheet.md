**moto reports no prices**, and a course about data on AWS that never quotes a price would leave
out half of every decision in it. So the prices come from where AWS publishes them: a public list
in JSON, readable with no account and no key. The program below reads one pinned version of it for
São Paulo and prints every price this course quotes. **Copy it with the button on the block and save
it as `~/aws/prices.py`**: `nano prices.py` opens an editor, the terminal's paste puts the program
in, and Ctrl+O, Enter and Ctrl+X save it and leave. The notes beside the code are not copied.

## How to read a line

Every number is **USD, before tax, for sa-east-1**, read from the offer version pinned in the
program, and every one was published in September or October 2026. A price on AWS's own pages may
have moved since; the one here will not, which is what lets a lesson say "0.0405" and mean it. When
a lesson quotes a line it names the block, so you can run that block and see it yourself.

**Two things the sheet is not.** It is not your bill: a bill is these prices multiplied by what you
used, plus tax, minus whatever discount an account has negotiated, and nothing in this course has a
bill, because nothing in it touches a real account. And it is not every price: S3 alone has 399
price rows in São Paulo, and the S3 block prints the 18 the lessons use.

**São Paulo costs more than Virginia.** A gigabyte of S3 Standard is 0.0405 a month here, and the
same list for us-east-1 says 0.023, which is what `cloud` lesson 5 printed with the two regions side
by side. This course stays in São Paulo, because a Brazilian company's data
usually has to, and lesson 5 of this course counts what moving it out would cost.
