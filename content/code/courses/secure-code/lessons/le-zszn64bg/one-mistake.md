Lesson 5 showed a value reaching SQL as code. **SQL is one interpreter among several**, and an
ordinary web application hands text to more of them than its authors usually count. This lesson takes
the three that the portal's staff console uses:

| interpreter | what it reads | its special characters, for example |
|---|---|---|
| the **shell** | a command line | spaces, `;`, `&`, `|`, `$`, quotes, a leading `-` |
| an **LDAP** directory | a search filter such as `(cn=carla)` | `*`, `(`, `)`, `\` |
| a **template engine** (Jinja) | a template such as `Hello {{ patient }}` | `{{`, `{%`, `{#` |

The wrong idea is that each of these needs its own expert knowledge of what is dangerous. The
dangerous characters differ, and **the mistake is the same each time**: a value is written into
text that an interpreter will parse, so some of the value is read as program. And the fix is the same
each time, too: **keep the program and the values in separate channels**, the way lesson 5's
placeholders did.

| interpreter | the separate channel |
|---|---|
| the shell | no shell at all: a list of arguments passed straight to the program |
| LDAP | the library's filter escaping, which turns every special character into plain data |
| Jinja | the value passed as a template **variable**, never joined into the template's text |

Escaping appears in the middle row, and it is there because LDAP filters have no placeholder
mechanism. **Where a separate channel exists, use it; escape only where none does**, and use the
library's escaping function rather than writing your own, because the library's author has read the
specification and you have a deadline.

### How to recognise it

All three flaws in the staff console have the same look in a diff: an f-string, a `+` or a
`.format()` building a string that is then handed to something that **parses** it. Searching a
codebase for `shell=True`, `os.system`, `search(` and `render_template_string(` finds the places to
look. What to look for at each place is whether anything in the string came from a request.
