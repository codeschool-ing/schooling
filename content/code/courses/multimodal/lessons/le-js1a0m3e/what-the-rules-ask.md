The Web Content Accessibility Guidelines, **WCAG 2.2**, are the standard most laws point to, and this platform is held to level AA itself. Their success criteria for media are short and specific:

| criterion | level | what it asks for prerecorded media |
|---|---|---|
| 1.1.1 Non-text Content | A | a text alternative for every image that carries meaning, such as `alt` text |
| 1.2.1 Audio-only and Video-only | A | a transcript for audio with no video, such as a recorded call or a podcast |
| 1.2.2 Captions | A | captions for all the speech and the sounds that matter in a video |
| 1.2.3 Audio Description or Media Alternative | A | a description of what is shown, or a full text alternative to the video |
| 1.2.5 Audio Description | AA | a description of what is shown, in the soundtrack |
| 1.2.7 Extended Audio Description | AAA | the video pauses when the narration leaves no room to describe |

Live media has its own criterion, 1.2.4 Captions (Live), at AA, which this lesson does not cover.

In Brazil, the **Lei Brasileira de Inclusão** (Lei 13.146/2015) makes accessibility compulsory on websites kept by companies with headquarters or a commercial presence in the country, in its article 63, and points to the practices adopted internationally, which in practice means WCAG.

Each row is a conversion this course has already made. A transcript is lesson 7's speech-to-text. Captions are the same text with times and line breaks, lesson 10's `vtt` format. A spoken description is lesson 6's text-to-speech. And alt text is what lesson 8's vision model wrote about a cover, shorter. **The machine can draft every one of them.** The rest of this lesson is about how good the drafts are, and where a person has to finish them.
