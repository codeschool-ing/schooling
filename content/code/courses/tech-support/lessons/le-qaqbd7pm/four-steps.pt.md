1. **Reproduzir.** Veja o defeito você mesmo, e anote exatamente o que ele diz. Um defeito que você não
   viu é um relato, e um relato é a lembrança de alguém sobre uma tela.
2. **Isolar.** Descarte, uma por uma, as partes que funcionam, até sobrar um lugar. Uma boa checagem
   descarta uma parte grande do que sobra.
3. **Testar.** Faça **uma mudança** que consertaria aquele lugar se ele for a causa, e veja se conserta.
   Uma mudança, para o resultado querer dizer alguma coisa.
4. **Confirmar.** Rode de novo a checagem do passo 1, de onde o usuário está, e veja passar. Depois avise
   o usuário e anote qual era a causa.

O resto desta aula segue os quatro num chamado só. A Carla, no escritório, escreve às 00:18:

> *A intranet não abre no meu computador. Semana passada estava funcionando.*

O computador dela é o `pc1`. A intranet é uma página web num servidor chamado `srv1`, e todo mundo no
escritório a abre pelo nome `intranet`.
