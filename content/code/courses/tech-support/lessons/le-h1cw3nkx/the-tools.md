Remote access comes in two shapes, and the tools follow them:

| tool | what it gives | where you meet it |
|---|---|---|
| SSH | a command line on the other computer | Linux and macOS servers, and most of this course |
| RDP, Windows Remote Desktop | a Windows desktop of its own, usually one user at a time | Windows computers and servers |
| VNC | the screen that is already on, shared | Linux desktops, and many devices |
| remote support tools, such as TeamViewer, AnyDesk or Windows Quick Assist | the user's own screen, after they accept a code or a prompt | helping a person with what is on their screen |

- **Attended access**: the user is there, sees the session, and has agreed to it this time. It is what
  remote support is, most days.
- **Unattended access**: the technician can connect without anyone accepting, to a server or to a
  computer whose owner agreed to it in advance, in writing. It is convenient, and it is the kind that
  needs the strongest rules, because nobody is watching when it is used.

Whatever the tool, it is **installed and configured by the organisation**, not downloaded during a call.
The last section of this lesson explains why that rule matters more than any other here.
