title: The scam that uses these tools
version: 1
---

The tools in this lesson are also the most common way criminals get into people's computers, and the
method needs no technical skill at all: **somebody phones, says they are from IT or from the bank, and
asks the person to install a remote support tool** to fix an urgent problem. Once connected, they have
everything a technician would have.

A support team protects its users from this by being predictable:

- **Say publicly how real support works**: *we never phone you to ask you to install anything; our
  tool is already on your computer; we always give a ticket number.* A user who knows the rule can
  spot the exception.
- **Never ask a user to install remote access during a call**, even when it would be faster. Doing it
  once teaches them that it is normal.
- **When in doubt, call back** on a number the user already knows, not one the caller gave.
- **If it has happened**, it is a security incident, not a normal ticket: disconnect the computer from
  the network and escalate at once, lesson 7.
