title: A plataforma que você está lendo faz isso
version: 1

As aulas 1 a 7 observaram o assistente: o que ele fez, quanto levou, quanto custou, como as pessoas
reagiram. Daqui em diante o curso o **avalia**: decide, resposta por resposta, se a resposta prestava.
O primeiro tipo de avaliação é o que não precisa de julgamento nenhum, só de uma regra que um programa
consiga aplicar.

Você esteve do lado de quem recebe uma o tempo todo. Todo exercício deste curso é corrigido por um
corretor no servidor da plataforma, e o jeito como ele funciona é um resumo desta aula:

- **Existe um gabarito, escrito com antecedência.** Uma questão de múltipla escolha diz qual é a opção
  certa; uma lacuna lista as respostas que aceita. Nada é decidido na hora de corrigir que não tenha
  sido decidido quando a questão foi escrita.
- **A normalização é declarada, não presumida.** Uma lacuna diz se maiúsculas e acentos importam. Numa
  questão sobre uma palavra-chave de SQL não importam; numa questão sobre convenções de nome a diferença
  é o ponto. O corretor faz o que a questão diz, e uma questão que não diz nada é corrigida com rigor.
- **O veredito é binário.** Certo ou errado, nunca meio certo, porque nota parcial é uma decisão sobre
  avaliação que teria de ser tomada uma vez para todo tipo.
- **Uma resposta que o corretor não entende é um erro, não um acerto.** Um erro de digitação no tipo de
  uma questão não vira uma questão que todo mundo acerta.
- **O gabarito é conferido contra si mesmo.** Antes de uma questão ser publicada, a sua própria resposta
  passa pelo corretor e precisa ser aceita, porque uma questão de gabarito errado é a única falha que
  um sistema sem revisor humano não consegue absorver.

Cada um desses pontos vale para um assistente. O conjunto de avaliação é o gabarito. A comparação
declara quão frouxa é. Uma resposta passa ou falha em cada verificação. Uma verificação que não
consegue decidir diz isso. E as próprias verificações são testadas, porque uma regra que aprova tudo
não mede nada.

O que **não** vale é a parte que torna fácil corrigir um exercício: um exercício é perguntado numa
forma que tem uma resposta certa. A pergunta de um cliente não tem, e o resto desta aula é sobre até
onde um programa consegue chegar mesmo assim.
