Uma corrente, quatro elos: a placa decide os watts, os watts decidem o calor, o calor decide a
refrigeração, a refrigeração decide o barulho.

Se uma questão descreve um sintoma, situe-o nessa corrente antes de buscar o nome de um
componente. Uma máquina que é rápida e depois lenta não é uma máquina lenta.
