Cinco aparelhos, uma ideia: cada um deles traduz entre uma pessoa e um número, e cada número da
caixa é uma medição ou uma promessa.

Duas destas questões te dão uma figura com os nomes retirados. O resto é quase todo sobre separar
os dois tipos de número — então, quando uma perguntar se algo vale o que custa, pergunte antes se
alguém mediu.
