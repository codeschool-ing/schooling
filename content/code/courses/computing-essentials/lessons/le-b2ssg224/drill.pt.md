Uma ideia, três vezes: o formato de um soquete é a única coisa que dá para ver e a menos
informativa sobre ele. O protocolo, a velocidade e a energia são três negociações separadas que o
conector não reporta.

A última questão te dá o fundo de uma máquina com os nomes retirados. Tudo antes dela é sobre o
mesmo hábito — quando algo não funciona, nomeie os quatro elos e troque um.
