---
title: The questions that narrow, and the ones that do not
version: 1
---

A short list, in rough order of how much each one buys. They are worth knowing by heart, because
the value of a question is how much it removes and that is not obvious in the moment.

## Did it ever work?

**No** is a completely different investigation from **yes**. Something that has never worked was
probably never set up correctly — the wrong cable, the wrong port, a step missed — and nothing is
broken at all. Something that worked on Friday and not on Monday has a cause that arrived in
between, and there are not many candidates.

People almost never volunteer this, and it is the first thing to ask.

## What changed?

The answer is *nothing*, and the answer is wrong. Prompt it:

- an update, which installs itself and asks nobody;
- a cable moved, to clean, to reach a socket, to plug in something else;
- somebody else using the machine;
- a new device added, even one that seems unrelated;
- a change of place — a different room, a different power socket, a journey in a bag.

## Does it happen to somebody else?

A second user account on the same machine is one restart-free test that splits software into
*this installation* and *this person's settings.* It is the cheapest large cut available on a
computer.

## Does it happen on another machine?

The same split, one level up: this machine, or this network and this file and this service.

## Does it happen in safe mode?

Everything added since the machine was new, removed in one restart. Covered in the previous
section, and it belongs on this list because it is the highest-yield single test on a slow or
crashing computer.

## Is there a message, written down exactly?

An error message is a sentence somebody wrote on purpose, for this case, and it is the one piece
of hard evidence most people discard. *It said something about a file* is worthless; the exact
words, typed into a search, are frequently the whole answer.

**Photograph it.** A message on a screen that is about to be restarted is a fact with a short
life.

## And the ones that buy nothing

- **Whose fault is it?** It narrows nothing and it makes the person who knows what changed less
  likely to say so.
- **Is it a virus?** Almost never, and it is the explanation people reach for precisely when they
  have run out of structure. It is a hypothesis like any other and it needs a test.
- **Has it been like this a long time?** Only useful as *did it ever work*, and asked this way it
  gets you a feeling rather than a date.
