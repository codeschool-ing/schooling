Um backup responde a *o arquivo ainda está lá*. Esta seção responde à pergunta por baixo dela, que
é *alguma coisa ainda consegue abrir*.

As duas importam e só uma delas costuma ser pensada. Um arquivo perfeitamente preservado num
formato que nada lê é um arquivo preservado que você não consegue de volta.

## O teste dos vinte anos

Pergunte de qualquer coisa que você pretenda guardar: **se a empresa que faz este programa deixar
de existir, o que abre o arquivo?**

| | abre daqui a vinte anos | por quê |
|---|---|---|
| `.txt`, `.md`, `.csv` | certamente | o formato são os caracteres. Qualquer coisa lê |
| `.pdf` | muito provavelmente | uma norma aberta com dezenas de implementações |
| `.jpg`, `.png` | muito provavelmente | o mesmo, e implementados em todo lugar |
| `.docx`, `.xlsx` | provavelmente | normas publicadas, arquivos zip de XML por baixo |
| `.psd`, `.ai`, `.indd` | só com o programa daquela empresa | proprietários, e não documentados de propósito |
| uma nota num aplicativo | muitas vezes não abre | o formato é o banco de dados do aplicativo |

A última linha é a de vigiar, porque é onde as notas e os diários da maioria das pessoas moram
hoje. **Um aplicativo de notas que não exporta para arquivos é um arquivo morto sem porta**, e a
exportação é a coisa a testar antes de ter cinco anos de notas dentro dele.

## A regra, numa linha

**Trabalhe no que for confortável; arquive em algo simples.**

Ninguém está te pedindo para escrever num editor de texto puro. O ponto é que, quando um documento
termina, a cópia que você vai guardar por dez anos deveria estar num formato que não depende de um
fornecedor continuar no mercado e de uma versão de arquivo continuar suportada.

Para a maioria das coisas isso significa **exportar um PDF ao lado do original** — o arquivo
editável para o dia em que você precisar mudar, o PDF para o dia em que precisar ler.

## PDF/A, que é o de arquivamento

Um PDF comum pode se referir a fontes que ele não contém e a conteúdo que ele busca. O `PDF/A` é o
subconjunto feito para guardar: tudo embutido, nada externo, nenhum script. A maioria dos
programas o oferece na caixa de exportação e quase ninguém usa.

É o que arquivos públicos exigem, e é a resposta certa para um contrato, um diploma ou qualquer
coisa que você queira abrir exatamente como ela é hoje.

## O papel, e para que serve escaneá-lo

Escanear um documento faz dois serviços, e só o segundo exige algum cuidado:

- **Uma fotografia da página** prova o que ela dizia. Qualquer resolução acima de 200 dpi dá
  conta.
- **Um documento buscável** precisa de reconhecimento de texto, e é o que torna uma pasta com mil
  escaneamentos utilizável em vez de decorativa.

A aula três disse que o OCR inventa palavras plausíveis quando erra e que a falha não parece uma.
Para um arquivo, isso significa **guardar a imagem além do texto** — que é o que um PDF buscável
é: o escaneamento que você lê e uma camada de texto embaixo dele que você busca.

## E a última ideia deste curso

Tudo desde a aula um foi sobre uma máquina: as peças, as portas, os rádios, os arquivos. Esta é a
única parte disso que é sobre **tempo**.

Uma máquina dura cinco anos. Um formato dura o tanto que alguém continuar implementando. **Os
seus documentos deveriam ser legíveis pela pessoa que você vai ser quando nenhum dos hardwares
deste curso existir** — e o jeito de arranjar isso são as mesmas três frases: um formato simples,
uma cópia que não muda quando o original muda, e uma delas em outro lugar.
