One discipline: make the sheet say what it assumes, and build the thing that tells you when it is
wrong. Everything else here — the layout, the names, the lookups, the pivot, the check column —
is that sentence applied somewhere specific.

When a question describes a number that came out wrong, ask which of the two it was: a wrong
assumption, or a right assumption applied to the wrong rows.
