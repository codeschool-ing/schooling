Uma disciplina: fazer a planilha dizer o que ela supõe, e construir a coisa que te avisa quando
ela está errada. Todo o resto daqui — a disposição, os nomes, as consultas, a dinâmica, a coluna
de conferência — é essa frase aplicada a um lugar específico.

Quando uma questão descrever um número que saiu errado, pergunte qual dos dois foi: uma premissa
errada, ou uma premissa certa aplicada às linhas erradas.
