Nada aqui é difícil sozinho. Tudo aqui é fácil numa ordem e chato em outra, e uma tela preta é
uma lista e não uma parede.

A última questão te dá uma placa-mãe com os nomes retirados. O resto é quase todo sobre qual passo
ou qual verificação vem primeiro — então, quando uma descrever um sintoma, pergunte o que seria
eliminado pelo teste mais barato em vez de qual peça tem mais chance de estar quebrada.
