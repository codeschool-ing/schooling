Nothing here is hard on its own. Everything here is easy in one order and annoying in another,
and a blank screen is a list rather than a wall.

The last question gives you a motherboard with the names taken off. The rest are mostly about
which step or which check comes first — so when one describes a symptom, ask what would be ruled
out by the cheapest test rather than which part is most likely to be broken.
