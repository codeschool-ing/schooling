Tudo que a aula anterior disse sobre estrutura vale aqui sem mudança: **um título é um título
porque é marcado como um**, um sumário sai dali, e o esquema na margem esquerda é o painel de
navegação com outro nome.

O que muda é o alcance. O Docs tem talvez um quinto dos recursos do Word, e para a maioria dos
documentos esse é o quinto certo.

| | Docs | Word |
|---|---|---|
| estilos | um punhado, editados no lugar | um sistema completo com herança |
| seções e configuração de página | um layout, na maior parte | quebras de seção e tudo que elas permitem |
| referências e citações | básicas, mais complementos | bibliografias, referências cruzadas, legendas |
| mala direta | um complemento | nativa |
| colaboração | a razão de ele existir | possível, através de um servidor |
| offline | arranjado de antemão | é um arquivo, então sempre |

**O resumo honesto é que o Docs é melhor naquilo que as pessoas de fato fazem e pior nas coisas
que aparecem na página quatrocentos de um manual.** Uma carta, um relatório, um conjunto de notas,
uma proposta: Docs. Uma tese com figuras numeradas, um livro com cabeçalhos por seção, uma mala
direta para seiscentos endereços: Word.

## Ajustar um estilo, que é feito ao contrário

No Word você edita o estilo e tudo acompanha. No Docs você **formata um parágrafo do jeito que
quer, depois abre o menu de estilos, depois *Atualizar Título 1 para corresponder***.

Mesmo resultado, ordem oposta, e pega todo mundo uma vez. Existe também *Opções, Salvar como meus
estilos padrão*, que leva as suas escolhas para documentos novos — o mais perto de um modelo que o
Docs tem, e vale fazer uma vez.

## As três coisas que o Docs tem e o Word não

- **O `@` em qualquer lugar.** Digitar `@` oferece pessoas, documentos, datas e um menu de blocos
  — uma tabela, uma lista de tarefas, uma lista suspensa. É a coisa mais rápida do produto e quase
  ninguém usa.
- **Comentários que viram tarefas.** Atribuir um comentário a alguém põe aquilo na lista da pessoa
  e manda um e-mail. Um comentário sem dono é um comentário que ninguém responde.
- **Nomear versões.** *Arquivo, Histórico de versões, Nomear versão atual* marca um ponto ao qual
  você volta por nome em vez de caçar entre horários. Faça antes de uma edição grande, não depois.

## Exportar, e o que a exportação é

*Arquivo, Fazer download* produz um `.docx`, um `.pdf`, um `.odt`, texto puro ou uma página web. O
`.docx` é uma **tradução**, não o documento: o Google renderiza o modelo dele no da Microsoft, e
os dois não têm os mesmos recursos.

O que sobrevive limpo: texto, títulos, listas, tabelas, imagens, comentários. O que se desloca:
espaçamento preciso, algumas bordas de tabela, qualquer coisa vinda de um complemento, e quebras
de página num documento longo.

**Para qualquer coisa que vá ser lida e não editada, mande o PDF.** É o mesmo conselho do problema
de fontes da aula anterior, pelo mesmo motivo: um formato que já tomou todas as decisões de layout
não consegue tomar uma diferente na máquina de outra pessoa.
