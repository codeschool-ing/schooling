One place per file, and a path is its only real name. Everything else — a shortcut, a recent
list, a search result — is a nickname that can be wrong.

One of these questions is about the extension being a label rather than a fact. Most of the rest
come back to where the work is: **the machine can find anything that was written down, and nothing
that was not.**
