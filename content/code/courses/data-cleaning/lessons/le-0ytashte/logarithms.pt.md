Os totais dos pedidos são assimétricos: a maioria é pequena, alguns são muito grandes. A média é
puxada pelos grandes, um histograma em reais é uma barra alta e uma cauda longa e vazia, e toda
escala da seção anterior sofreu com isso. **Um logaritmo transforma multiplicação em soma**, então
R$ 10, R$ 100 e R$ 1.000 viram 1, 2 e 3, igualmente espaçados, e a cauda se dobra para dentro.

O logaritmo tem uma regra dura: só existe para números positivos. Este conjunto de dados tem
zeros, os 137 pedidos com cupom que a aula 9 decidiu que não foram cobrados:

```
ana@lab:~/clean$ python -c "import numpy as np; from ready import orders; t = orders['total']; print((t == 0).sum()); print(np.log10(t).min())" 2>&1
/home/ana/venv/lib/python3.12/site-packages/pandas/core/arraylike.py:402: RuntimeWarning: divide by zero encountered in log10
  result = getattr(ufunc, method)(*inputs, **kwargs)
137
-inf
```

O Python imprime um aviso uma vez, na saída de erro, e segue em frente: **o logaritmo de zero é menos
infinito**, e um único `-inf` transforma toda média, desvio padrão e soma calculados a partir da
coluna em `-inf` ou `NaN`. Num notebook o aviso passa rolando. Num processo agendado ninguém o lê.

Há três saídas honestas, e cada uma diz uma coisa diferente:

- **Deixar os zeros de fora**, como vazios, e dizer quantos são. A coluna em log passa a descrever
  pedidos que foram pagos, o que muitas vezes é a pergunta.
- **Somar uma constante antes**, `log10(total + 1)`, o que mantém toda linha. É comum e entorta os
  valores pequenos: R$ 0,25 e R$ 0 ficam próximos, e o resultado deixa de ser um logaritmo de
  dinheiro.
- **Guardar os zeros numa coluna separada**, uma marca como `free_order`, e aplicar o log ao resto.
  Um modelo ou um gráfico pode então usar as duas.

Esta aula fica com a primeira:


```
ana@lab:~/clean$ python logs.py
blank logs: 137
mean 93.87  median 57.60  geometric mean 60.14
skew: total 65.2, log_total 0.02
```

A assimetria dos totais é 65,2; a dos logaritmos, 0,02, praticamente simétrica. E a média dos
logaritmos, desfeita com `10 **`, é a **média geométrica**, R$ 60,14: muito mais perto da mediana
de R$ 57,60 do que a média aritmética de R$ 93,87. Para um valor assimétrico, a média geométrica
muitas vezes é o "pedido típico" que as pessoas procuram quando pedem uma média.
