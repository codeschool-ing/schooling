**Um array é um bloco de bytes mais uma descrição de como lê-lo.** O bloco é plano: a memória não
tem linhas nem colunas. A descrição, o formato, o dtype e os **strides**, é o que o transforma numa
tabela. Ver essa divisão explica por que algumas operações não custam nada e outras copiam tudo.

Pegue a tabela 4 × 6 de horas de duas seções atrás:

```python
hours = np.arange(24).reshape(4, 6)
hours.strides, hours.flags["C_CONTIGUOUS"]
```
```
((48, 8), True)
```

`strides` diz quantos bytes pular para andar um passo ao longo de cada eixo. Andar ao longo de uma
linha, para a próxima coluna, são 8 bytes: um `int64`. Descer uma coluna, para a próxima linha, são
48 bytes: uma linha inteira de seis. O bloco guarda a linha 0, depois a 1, depois a 2, uma após a
outra, o que o NumPy chama de **ordem C**, por causa da linguagem que dispõe os arrays do mesmo
jeito.

## Uma transposição não move nada

`hours.T` troca linhas e colunas. Faz isso trocando os strides, não os números:

```python
flipped = hours.T
flipped.shape, flipped.strides, flipped.flags["C_CONTIGUOUS"]
```
```
((6, 4), (8, 48), False)
```

Os mesmos 24 números nos mesmos bytes, agora lidos com 8 bytes até a próxima linha e 48 até a
próxima coluna. Não levou tempo nem memória, qualquer que seja o tamanho do array. O que ele perdeu
foi a contiguidade: o array transposto não está mais guardado linha após linha, e uma operação que
precise das linhas uma depois da outra vai fazer uma cópia antes. `np.ascontiguousarray` faz essa
cópia de propósito quando você quer pagar por ela uma vez.

## Por que isso importa na prática

- **Ler ao longo do último eixo é o mais rápido.** Os números estão vizinhos, então o cache do
  processador traz os seguintes de graça. Somar cada linha de um array grande em ordem C é mais
  rápido do que somar cada coluna, com o mesmo resultado.
- **`reshape` de um array contíguo é de graça**, porque um formato novo são só strides novos sobre o
  mesmo bloco. O `-1` em `reshape(-1, 6)` pede ao NumPy que calcule esse eixo a partir do tamanho.
- **Algumas operações precisam de cópia e a fazem sem perguntar.** `ravel` devolve o bloco plano
  quando pode e uma cópia quando a ordem não deixa; `flatten` sempre copia. A próxima seção mostra
  como saber o que você recebeu, porque isso decide se uma mudança que você faz aparece em outro
  lugar.
