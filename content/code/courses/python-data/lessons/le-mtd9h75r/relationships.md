**A scatter plot puts one variable against another, a point per row, and shows how they move
together.** It is also where a fitted line is most tempting, and where one most easily says something
the data does not.

One row per day, with its trips and its weather, the merge of lesson 14:

```python
weather = pd.read_csv("weather.csv")
weather["date"] = pd.to_datetime(weather["date"], format="%Y-%m-%d")
daily = trips.groupby(trips["started_at"].dt.normalize()).size().rename("trips")
days = daily.rename_axis("date").reset_index().merge(weather, on="date", validate="one_to_one")
days["weekend"] = days["date"].dt.dayofweek >= 5
days.shape
```

```
(365, 5)
```

Trips against rain, with weekends in another colour:

```python
fig, ax = plt.subplots(figsize=(8, 3.5), layout="constrained")
sns.scatterplot(data=days, x="rain_mm", y="trips", hue="weekend", ax=ax);
```

## What a straight line would say

`sns.regplot` fits a straight line through a scatter. Through these points it would slope gently
downwards across the whole range, saying each millimetre of rain costs a few trips. The data says
something else, and grouping the rain into bands shows it:

```python
bands = pd.cut(days["rain_mm"], bins=[-0.1, 0, 5, 10, 20, 50])
days.groupby(["weekend", bands], observed=True)["trips"].mean().round(1).unstack("weekend")
```

```
weekend       False  True 
rain_mm                   
(-0.1, 0.0]   109.7   70.4
(0.0, 5.0]    111.3   67.1
(5.0, 10.0]   109.7   70.1
(10.0, 20.0]   61.3   40.4
(20.0, 50.0]   61.9   42.3
```

From dry to 10 mm, a weekday has about 110 trips whatever the rain. Above 10 mm it has about 61.
That is a **step**, not a slope, and a straight line through a step is wrong at both ends: too low on
light rain, too high on heavy. The program in lesson 8 makes exactly that step, `rain > 10`, and real
data has shapes like it more often than straight lines.

**Look at the scatter before fitting anything to it**, and when the shape is not a line, a table of
means by band, like this one, often says more than any fitted curve.
