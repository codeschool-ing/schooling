**Uma distribuição é o formato de uma coluna: onde os valores se juntam, quanto se espalham, e o que
fica nas pontas.** Uma média diz uma dessas três coisas. Um gráfico diz as três, e o gráfico certo
depende de qual você precisa comparar.

As durações de viagem têm uma cauda longa à direita: a maioria das viagens é curta, algumas são muito
longas. Os números primeiro:

```python
trips.groupby("plan")["minutes"].quantile([0.5, 0.9, 0.99]).round(1).unstack()
```

```
        0.50  0.90  0.99
plan                    
annual  12.4  23.8  40.1
day     19.9  38.3  65.4
```

Metade das viagens dos assinantes fica abaixo de 12,4 minutos, nove em dez abaixo de 23,8, e uma em
cem passa de 40. Os passes diários chegam a 65 minutos no mesmo ponto. **O percentil 99 é o triplo da
mediana** nos dois planos, que é o que uma cauda longa quer dizer.

A caixa vai do primeiro quartil ao terceiro, então contém a metade do meio das viagens, e a linha
dentro dela é a mediana. Os bigodes alcançam a viagem mais distante a até uma vez e meia o comprimento
da caixa, e toda viagem além deles é desenhada como um ponto separado. Esses pontos são o que um box
plot chama de **outliers**, e são muitos:

```python
def beyond_whiskers(m):
    q1, q3 = m.quantile([0.25, 0.75])
    return int((m > q3 + 1.5 * (q3 - q1)).sum())

trips.groupby("plan")["minutes"].agg(beyond_whiskers)
```

```
plan
annual    843
day       364
Name: minutes, dtype: int64
```

Centenas de viagens por plano são "outliers" por essa regra, e nenhuma delas é erro: uma cauda longa é
uma propriedade dos dados, e o gerador da aula 8 tira as durações de uma distribuição que tem uma.
**Um ponto além de um bigode é um valor para olhar, não um valor para apagar.** Apagá-los tiraria as
viagens mais longas de todo cálculo seguinte, e o percentil 99 acima encolheria em silêncio.

As bicicletas perdidas não aparecem em nenhum dos dois gráficos. Os `minutes` delas são `NaN`, e o
seaborn, como o pandas, deixa faltantes de fora sem avisar; 146 viagens faltam nos dois gráficos, o
que num gráfico de durações é a resposta certa e ainda assim vale saber.
