**`plt.subplots(linhas, colunas)` cria uma grade de eixos numa figura, e `sharey=True` lhes dá uma
escala vertical só, para que barras em gráficos diferentes se comparem a olho.** Dois gráficos lado a
lado em escalas diferentes convidam justamente à comparação que não sustentam.

Viagens por hora do dia, em dias úteis e no fim de semana. Há 261 dias úteis e 104 dias de fim de
semana em 2025, então as contagens são divididas pelo número de dias de cada tipo, o que dá viagens
por dia em cada hora:

```python
trips["hour"] = trips["started_at"].dt.hour
trips["weekend"] = trips["started_at"].dt.dayofweek >= 5
days = pd.Series(daily.index.dayofweek >= 5).value_counts()
per_hour = trips.groupby(["weekend", "hour"]).size().unstack("weekend") / days
per_hour.round(1).loc[[7, 12, 17]]
```

```
weekend  False  True 
hour                 
7         11.7    3.2
12         5.0    4.6
17        10.8    3.6
```

O `unstack` pôs os dois tipos de dia nas colunas, `False` e `True`, e dividir por `days` dividiu cada
coluna pela própria contagem, porque a divisão se alinha pelos rótulos, como a aula 9 mostrou. Às 7 da
manhã um dia útil tem mais que o triplo das viagens de um dia de fim de semana; ao meio-dia eles se
igualam.

Dois eixos numa linha, dividindo o eixo vertical:

```python
fig, axes = plt.subplots(1, 2, figsize=(9, 3.5), sharey=True, layout="constrained")
for ax, weekend, title in zip(axes, [False, True], ["Monday to Friday", "Saturday and Sunday"]):
    ax.bar(per_hour.index, per_hour[weekend])
    ax.set_title(title)
    ax.set_xlabel("hour")
axes[0].set_ylabel("trips per day")
fig.suptitle("Weekdays have two rush hours; weekends have none");
```

`axes` é um array NumPy de dois `Axes`, então um laço monta os dois do mesmo jeito e só o que difere é
escrito duas vezes. O `fig.suptitle` dá título à figura inteira, acima dos dois títulos dos eixos.

**O `sharey=True` é a linha que torna a comparação honesta.** Sem ele cada axes se ajusta aos próprios
dados: o gráfico do fim de semana, cuja barra mais alta fica abaixo de 5, se esticaria até a mesma
altura do gráfico dos dias úteis, cuja mais alta chega perto de 12, e os dois pareceriam iguais. Com
ele, as barras do fim de semana ficam visivelmente mais baixas, que é o fato que o gráfico existe para
mostrar. Gráficos desenhados assim, o mesmo gráfico repetido para cada grupo numa escala só, costumam
se chamar **pequenos múltiplos**, e em geral são mais claros que um gráfico lotado com todos os grupos.
