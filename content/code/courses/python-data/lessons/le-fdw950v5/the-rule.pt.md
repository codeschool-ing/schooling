**Broadcasting é como o NumPy combina dois arrays de formatos diferentes sem copiar nenhum: ele
estica o menor, ao longo dos eixos em que o comprimento é 1, até casar com o maior.** A aula 5 o
usou sem dizer, quando `np.maximum(temp, 30.0)` comparou 365 temperaturas com um número. Esta aula
dá a regra, porque o mesmo mecanismo que faz `temp - 30` funcionar produz alguns dos erros mais
confusos do NumPy, e um dos silêncios mais perigosos.

O notebook desta aula começa como o da anterior, com a tabela de semanas:

```python
import numpy as np

weather = np.genfromtxt("weather.csv", delimiter=",", skip_header=1, usecols=(1, 2))
rain, temp = weather[:, 0], weather[:, 1]
weeks = temp[:364].reshape(52, 7)
```

A regra, que o NumPy aplica aos dois formatos antes de fazer qualquer coisa:

> **Alinhe os formatos pela direita. Cada par de comprimentos tem de ser igual, ou um deles tem de
> ser 1. Um comprimento ausente conta como 1. O resultado fica com o maior comprimento em cada
> posição.**

Três casos, uma linha cada.

**Um número sozinho** tem formato `()`, nada para alinhar, então estica para tudo:

```python
(weeks - 30).shape
```

```
(52, 7)
```

**Uma linha de sete** contra uma tabela de 52 × 7. Alinhados pela direita, `7` encontra `7`, e o
comprimento ausente à esquerda conta como 1 e estica para 52. Então os mesmos sete números são
tirados de cada semana, que é exatamente "subtrair de cada dia da semana a média daquele dia":

```python
by_position = weeks.mean(axis=0)
(weeks - by_position).shape, by_position.shape
```

```
((52, 7), (7,))
```

**Uma coluna de 52**, escrita com formato `(52, 1)`, contra a mesma tabela. `1` encontra `7` e
estica, `52` encontra `52`. O número único de cada semana é tirado dos seus sete dias, "subtrair
de cada semana a média dela":

```python
weekly = weeks.mean(axis=1, keepdims=True)
(weeks - weekly).shape, weekly.shape
```

```
((52, 7), (52, 1))
```

`keepdims=True` mantém o eixo reduzido com comprimento 1, e o resultado fica `(52, 1)` em vez de
`(52,)`. Esse único argumento é a diferença entre o terceiro caso funcionar e o erro da próxima
seção.
