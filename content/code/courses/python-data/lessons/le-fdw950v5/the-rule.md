**Broadcasting is how NumPy combines two arrays of different shapes without copying either: it
stretches the smaller one, along the axes where its length is 1, to match the larger.** Lesson 5
used it without saying so, when `np.maximum(temp, 30.0)` compared 365 temperatures with one
number. This lesson gives the rule, because the same mechanism that makes `temp - 30` work makes
some of the most confusing errors in NumPy, and one of the most dangerous silences.

The notebook for this lesson starts like the last one's, with the weeks table:

```python
import numpy as np

weather = np.genfromtxt("weather.csv", delimiter=",", skip_header=1, usecols=(1, 2))
rain, temp = weather[:, 0], weather[:, 1]
weeks = temp[:364].reshape(52, 7)
```

The rule, which NumPy applies to the two shapes before doing anything:

> **Line the shapes up from the right. Each pair of lengths must be equal, or one of them must be
> 1. A missing length counts as 1. The result takes the larger length in every position.**

Three cases, each one line.

**A single number** has shape `()`, nothing to line up, so it stretches to everything:

```python
(weeks - 30).shape
```

```
(52, 7)
```

**A row of seven** against a table of 52 × 7. Lined up from the right, `7` meets `7`, and the
missing length on the left counts as 1 and stretches to 52. So the same seven numbers are taken
from every week, which is exactly "subtract each weekday's mean from that weekday":

```python
by_position = weeks.mean(axis=0)
(weeks - by_position).shape, by_position.shape
```

```
((52, 7), (7,))
```

**A column of 52**, written as shape `(52, 1)`, against the same table. `1` meets `7` and stretches,
`52` meets `52`. Each week's single number is taken across its seven days, "subtract each week's mean
from its days":

```python
weekly = weeks.mean(axis=1, keepdims=True)
(weeks - weekly).shape, weekly.shape
```

```
((52, 7), (52, 1))
```

`keepdims=True` keeps the reduced axis with length 1, so the result is `(52, 1)` instead of `(52,)`.
That one argument is the difference between the third case working and the error in the next
section.
