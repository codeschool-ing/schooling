Um **banco de séries temporais** guarda medidas: um valor, uma hora e alguns rótulos dizendo o que
foi medido. Ingressos vendidos por minuto, a latência de cada pedido, a temperatura de um servidor.
Os dados têm um formato que tabelas relacionais conseguem guardar e que esta família aproveita:

- **Eles chegam em ordem de tempo e quase nunca mudam.** As escritas são acréscimos no fim.
- **Eles são lidos por faixas de tempo**, "a última hora", e geralmente agregados: médias, somas,
  percentis por minuto.
- **O valor deles cai com a idade.** Os números por segundo de ontem importam; os do ano passado só
  importam como totais diários.

O quinto padrão de acesso da seção 03, vendas por minuto para um painel, é as três coisas. Um ponto
no **line protocol** do InfluxDB, o formato de texto que ele recebe, é assim:

```
sales,show=1,channel=web tickets=3i 1794776400000000000
```

A medida é `sales`; `show` e `channel` são **tags**, rótulos indexados para filtrar e agrupar;
`tickets=3i` é um **campo**, o valor, um inteiro aqui; o último número é a hora em nanossegundos.

## O que a família faz com esse formato

- **Compressão.** Horas consecutivas diferem por intervalos parecidos e valores consecutivos são
  próximos, então guardar diferenças em vez de valores encolhe os dados muitas vezes.
- **Retenção.** Dados mais velhos que uma idade definida são descartados sozinhos, partição por
  partição, do jeito que a aula 2 descartou um mês: apagando arquivos, não linhas.
- **Redução de amostragem** (*downsampling*). Os pontos brutos são condensados em outros mais
  grossos, um por minuto, depois um por hora, e os brutos são descartados. Um ano de dados por
  segundo vira um ano de dados por hora que ainda responde toda pergunta que alguém faz sobre o ano
  passado.

## O custo: a cardinalidade

Toda combinação de valores de tags é uma **série** separada, com as próprias entradas no índice.
`show` com cem valores e `channel` com três dão 300 séries, o que não é nada. Uma tag com um valor
por comprador, ou por pedido, dá milhões, e o índice não cabe mais na memória. **Tags são para as
poucas dimensões pelas quais você agrupa; qualquer coisa com muitos valores é um campo**, que não é
indexado. A aula 7 encontra exatamente esse problema nos rótulos do Prometheus, que é a mesma ideia
num sistema de monitoramento.
