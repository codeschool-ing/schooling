title: Two ways to say the same thing
version: 1
---

There are two ways to tell a machine to produce the morning report.

**Imperatively**: a list of steps, in order. Load raw, then build the models, then write the file.
The machine does what it is told, in the order it is told, every time it is told. It knows nothing
about why: it cannot skip a step whose work is already done, because it was never told what any
step's work *is*.

**Declaratively**: a description of what should exist and what each thing is made from. The report
is made from the models, the models from raw, raw from the shop. The machine works out the steps
— and, given a way to tell what is out of date, which of them need running at all.

Every tool in this course sits somewhere between the two. A shell script is purely imperative. A
dbt project is purely declarative: a model is a `select`, a statement of what the table should
contain, and dbt writes the steps. An Airflow DAG is a declared graph of imperative tasks: the
arrows say what depends on what, and each box is a command. Luigi and Dagster are declarations of
outputs; Prefect is a function that calls things in order.

The difference stops being academic on the second run, and on the run after a failure. This lesson
writes the nightly both ways and runs each one more than once.
