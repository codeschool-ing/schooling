**2,048 tokens for the twelve turns, against 4,609 for the whole history**, and the prompt no longer
grows: it is the state, the documents of this turn and the question, whatever happened before.

The answers, turn by turn:

- **Turn 10** now searches with turn 3 in front of it, and **the first document is the right one**:
  "If we sent a different title from the one you ordered, tell us within 14 days", at 0.590, where
  the question alone found nothing above the floor. The reply is still the refusal sentence, and
  that part is extract-1: it copies sentences by their similarity to the question as asked, and no
  sentence of that paragraph is close to "How do I send back Mansfield Park?" without knowing that
  *Mansfield Park* is the wrong book. Connecting the two is exactly what a language model is for and
  this stand-in is not; the retrieval half, which a lab can measure, is fixed.
- **Turn 11** recalls turn 6 and finds the refunds section, as alone.
- **Turn 12** is answered from the state, "Your order number is MG-20481937. [1]", for 118 tokens.

So the memory that is cheapest to send also answered more. That is not a coincidence of this
conversation: whole history sends everything in case it matters, and memory sends what was chosen
because it does. It is lesson 12's argument again, applied to the past instead of the documents.

The measure that would settle it for a deployment is lesson 8's, extended to conversations: a set of
chats with the question at the end and the fact the answer must contain, run with each memory against
the real model. Two chats are a demonstration, not that test.
