**2,346 tokens for the twelve turns, against 8,070 for the whole history**, and the prompt no longer
grows: it is the state, the documents of this turn and the question, whatever happened before.

The answers, turn by turn:

- **Turn 7** says to send the photographs to the customer service team, with no invented address:
  the reply stayed inside its sources.
- **Turn 10** now searches with turn 3 in front of it, and **the first document is the right one**:
  "If we sent a different title from the one you ordered, tell us within 14 days", at 0.590, where
  the question alone found nothing above the floor. The reply walks through the return steps for
  *Mansfield Park*, cited, and adds a note with the order number taken from the state.
- **Turn 11** recalls turn 6, finds the refunds section, and answers: three working days from the
  return reaching the warehouse, for *Middlemarch*. Alone, the same section was found and refused.
- **Turn 12** is refused, as the previous section showed, with the order number in the state.

So the memory that is cheapest to send also answered more: two of the three questions that needed the
past, where the whole history answered one. That is not a coincidence of this conversation: whole
history sends everything in case it matters, and memory sends what was chosen because it does. It is
lesson 12's argument again, applied to the past instead of the documents. The question it missed is
the one that should never have been the model's.

The measure that would settle it for a deployment is lesson 8's, extended to conversations: a set of
chats with the question at the end and the fact the answer must contain, run with each memory against
the real model. Two chats are a demonstration, not that test.
