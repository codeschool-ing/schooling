"The data is encrypted" is one of the most reassuring sentences in a security review and one of
the least informative. Encrypted **where**, with a key held **by whom**, against **which**
person? Each answer changes what the sentence is worth.

The data of a customer travels and rests in several places between the website and a backup tape,
and each place has a different kind of person who could read it:

| where the data is | who could read it if nothing stopped them | what stops them |
|---|---|---|
| on the network, between a client and the server | anybody on the path: a shared Wi-Fi, a misconfigured switch, a compromised router | **TLS**, encryption in transit |
| in the server's data files | whoever gets the disk: a stolen laptop, a decommissioned drive, a snapshot copied out of a cloud account | **disk or volume encryption**, at rest |
| in a backup or an export | whoever gets the file, which travels further and lives longer than the database | encrypting the **file**, with a key that is not beside it |
| inside the running database | anybody with a role that can `SELECT` it, the superuser, and whoever can read the server's memory | **grants and policies** (lessons 1 and 2), and encrypting **before** the data reaches the database |

The last row is the one people forget. **Every form of encryption ends somewhere**, and past that
point the data is plaintext again: TLS ends at the server, disk encryption ends when the
operating system reads the block, and both are invisible to a `SELECT`. An analyst with the
wrong grant reads a perfectly encrypted disk in clear.

So the question this lesson keeps asking is not "is it encrypted?" but **"where does the
encryption end, and who is standing there?"** The answers for Ipê's database take the rest of
the lesson. Where the keys come from is lesson 4.

## Two words

**In transit** means while it moves: between a client and the server, between the server and a
replica, between a pipeline and the warehouse. **At rest** means while it is stored: the data
files, the write-ahead log, temporary files, backups, exports, the copy somebody saved to their
laptop. A system with only one of the two has a gap exactly the shape of the other.
