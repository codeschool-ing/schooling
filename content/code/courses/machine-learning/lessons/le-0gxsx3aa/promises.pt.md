A mediana é o tempo que metade das entregas vence. Uma promessa que deve ser cumprida nove vezes em
dez precisa do tempo que **nove entregas em dez vencem: o percentil 90**, para aquele tipo de viagem.
Modelos conseguem prever isso diretamente. A **regressão quantílica** ajusta um percentil escolhido em
vez da média ou da mediana, e o gradient boosting faz isso com `loss="quantile"`.

A perda que ela minimiza é o motivo de funcionar, e é a ideia da aula 11 de novo. Para o percentil 90,
um erro do lado do atraso custa 0,9 por minuto, e do lado adiantado, 0,1. Atrasar é nove vezes mais
caro que adiantar, então o modelo puxa as previsões para cima até que, nas linhas de treino, cerca de
uma entrega em dez atrase. Isso se chama **perda pinball**, pela forma do gráfico:

Salve isto como `promise.py`; ele ajusta quatro percentis e trata cada um como a promessa:

```python
# promise.py
import pandas as pd
from sklearn.ensemble import HistGradientBoostingRegressor

deliveries = pd.read_csv("data/deliveries.csv", parse_dates=["date"])
deliveries["rush"] = deliveries["hour"].isin([11, 12, 17, 18, 19]).astype(int)
train = deliveries[deliveries["date"] < "2025-10-01"]
test = deliveries[deliveries["date"] >= "2025-10-01"]
features = ["distance_km", "items", "rush", "rain", "driver_months"]

print("quantile   average promise   late   late by more than 10 min")
for quantile in [0.5, 0.8, 0.9, 0.95]:
    model = HistGradientBoostingRegressor(loss="quantile", quantile=quantile, random_state=0)
    promise = model.fit(train[features], train["minutes"]).predict(test[features])
    late_by = test["minutes"] - promise
    print(f"{quantile:8.2f} {promise.mean():13.1f} min {(late_by > 0).mean():7.1%}"
          f" {(late_by > 10).mean():12.1%}")
```

**A linha de 0,5 é o `boost_absolute` de novo**: a mediana e o erro absoluto são o mesmo alvo. Cada
linha acima dela compra pontualidade com paciência. O modelo de 0,8 atrasa 23,0% das vezes e promete
3,4 minutos a mais em média; o de 0,9 atrasa 13,7% e promete 7 minutos a mais. Nos meses de teste a
parte atrasada fica alguns pontos acima do que cada modelo mirou. O quantil é atingido nas linhas de
onde o modelo aprende, e em meses novos ele é aproximado, o que vale conferir em vez de supor.

Olhe a última coluna também. Mesmo o modelo de 0,95 atrasa mais de dez minutos em 2,9% das entregas,
porque essas são as vans paradas, e nenhuma promessa que não seja absurda cobre um pneu furado.

**Que quantil usar é uma decisão do negócio, tomada como a aula 11 tomou o corte.** Se um minuto de
atraso custa ao negócio quatro vezes o que custa um minuto adiantado, o melhor quantil é 4 / (4 + 1) =
0,8. Um minuto adiantado não é de graça: uma estimativa sempre folgada é uma que os clientes aprendem a
ignorar. O trabalho de quem faz ciência de dados é a tabela acima; quem atende as reclamações é dono da
proporção.
