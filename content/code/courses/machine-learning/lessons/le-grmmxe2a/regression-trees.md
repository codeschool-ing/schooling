A regression tree asks the same questions and predicts, at each leaf, the **mean** of the training
rows that ended there. The cut is chosen to make the leaves' values as similar as possible, by the
squared differences, in place of Gini. Everything else is the same, including the brakes. Save this
as `tree_minutes.py`:

```python
# tree_minutes.py
import pandas as pd
from sklearn.tree import DecisionTreeRegressor

deliveries = pd.read_csv("data/deliveries.csv", parse_dates=["date"])
features = ["distance_km", "items", "hour", "rain", "driver_months"]
train = deliveries[deliveries["date"] < "2025-10-01"]
test = deliveries[deliveries["date"] >= "2025-10-01"]

for leaf in [1, 20, 100]:
    tree = DecisionTreeRegressor(min_samples_leaf=leaf, random_state=0)
    tree.fit(train[features], train["minutes"])
    error = (test["minutes"] - tree.predict(test[features])).abs().mean()
    print(f"min_samples_leaf={leaf:<4} {tree.get_n_leaves():5,} leaves, off by {error:4.1f} minutes")

far = pd.DataFrame({"distance_km": [20, 30, 45, 60], "items": 17, "hour": 15, "rain": 0,
                    "driver_months": 30})
print("predicted minutes at 20, 30, 45 and 60 km:", tree.predict(far[features]).round(1).tolist())
print(f"longest training delivery: {train['distance_km'].max()} km")
```

The best of the three trees is off by **7.4 minutes**, which beats every rule of lesson 2 and loses to
lesson 5's line, at **5.9**. That is not a failure of trees in general; it is what happens when the
data is close to linear. Delivery time really does grow steadily with distance and items, and a
tree can only approximate a slope with a staircase of flat steps, each one a leaf. The line has the
right shape by construction.

The last two lines show the other limit. **A tree predicts the same 77.8 minutes for 20, 30, 45 and
60 km**, because the longest training delivery was 29 km and every leaf is a mean of rows that
existed. In fact the staircase goes flat well before 29 km, where deliveries become rare and the
leaves stop dividing them. Past the edge of the data, a tree repeats its last step for ever:

The line from lesson 5 carries on rising, which is roughly right. The tree stays flat, which is wrong
in a way that grows with every kilometre. For predictions inside the range of the training data, the
difference does not matter. For a business that is about to start delivering further than it ever
has, it is the whole question, and no tree-based model, however many trees it averages, can answer
it.
