A aula 2 deixou um número a superar: a melhor regra simples para o tempo de entrega, a mediana por
hora do dia, errava por **10,9 minutos** em média. As regras falharam por um motivo em especial: uma
entrega tem uma parte fixa e uma parte que cresce com a distância, e nenhuma delas tinha espaço para
as duas. A **regressão linear** tem espaço exatamente para isso, e para mais um termo por coluna:

`minutes = intercept + w₁ × distance + w₂ × items + w₃ × rush + …`

Ajustar quer dizer escolher o intercepto e os pesos `w` que deixam as previsões o mais perto possível
dos minutos reais nas linhas de treino, onde "perto" é medido pelas diferenças ao quadrado. Existe
uma fórmula para a melhor escolha, então não há busca nem acaso: as mesmas linhas sempre dão a mesma
reta.

Uma coluna é feita antes do ajuste. A hora do dia é um número de 8 a 20, e uma reta o leria como
*mais tarde é mais lento*, que não é como o trânsito funciona. O que importa é se a hora é de pico,
então `rush` vale 1 às 11, 12, 17, 18 e 19 horas e 0 no resto. A aula 14 trata de escolhas como
esta. Salve isto como `linear.py`:

```python
# linear.py
import pandas as pd
from sklearn.linear_model import LinearRegression

deliveries = pd.read_csv("data/deliveries.csv", parse_dates=["date"])
deliveries["rush"] = deliveries["hour"].isin([11, 12, 17, 18, 19]).astype(int)
train = deliveries[deliveries["date"] < "2025-10-01"]
test = deliveries[deliveries["date"] >= "2025-10-01"]

features = ["distance_km", "items", "rush", "rain", "driver_months"]
line = LinearRegression().fit(train[features], train["minutes"])

print(f"intercept      {line.intercept_:6.2f} minutes")
for name, coef in zip(features, line.coef_):
    print(f"{name:14} {coef:+6.2f}")
error = (test["minutes"] - line.predict(test[features])).abs().mean()
print(f"off by {error:.1f} minutes on average, on the test months")
```
