A PCA guarda as direções de maior espalhamento, o que não é o mesmo que manter os grupos separados. Dois
outros métodos miram o retrato diretamente:

- O **t-SNE** (t-distributed stochastic neighbour embedding) descobre, para cada cliente, quais outros são
  seus vizinhos próximos em oito dimensões, e depois põe todos numa página de modo que os mesmos clientes
  fiquem perto. Seu ajuste principal, a **perplexidade**, é mais ou menos a quantos vizinhos cada cliente
  presta atenção.
- O **UMAP** (uniform manifold approximation and projection) tem o mesmo objetivo, construído sobre outra
  matemática. Costuma ser mais rápido em dados grandes, tende a guardar mais da arrumação em grande escala,
  e consegue pôr linhas novas num mapa que já desenhou. Ele mora no pacote `umap-learn` que a aula 1
  instalou.

Os dois são julgados aqui por dois números. A **confiabilidade** (`trustworthiness`), do scikit-learn,
pergunta quantos dos dez vizinhos mais próximos de cada cliente no mapa também estavam perto dele nas oito
colunas: 1 quer dizer todos. A **silhueta** dos quatro grupos da aula 16, medida no mapa, pergunta quão
afastados os grupos aparecem. Salve isto como `maps.py`:

```python
# maps.py
import time

import pandas as pd
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE, trustworthiness
from sklearn.metrics import silhouette_score
from sklearn.preprocessing import StandardScaler
from umap import UMAP

baskets = pd.read_csv("data/baskets.csv")
scaled = StandardScaler().fit_transform(baskets.drop(columns="customer_id"))
groups = KMeans(n_clusters=4, n_init=10, random_state=0).fit(scaled).labels_

methods = {"PCA": PCA(n_components=2),
           "t-SNE, perplexity 30": TSNE(perplexity=30, random_state=0),
           "t-SNE, perplexity 5": TSNE(perplexity=5, random_state=0),
           "UMAP": UMAP(random_state=0, n_jobs=1)}
print("map                    seconds   neighbours kept   groups apart")
for name, method in methods.items():
    start = time.perf_counter()
    flat = method.fit_transform(scaled)
    seconds = time.perf_counter() - start
    print(f"{name:21} {seconds:8.1f} {trustworthiness(scaled, flat, n_neighbors=10):17.3f}"
          f" {silhouette_score(flat, groups):14.3f}")
```

O `n_jobs=1` mantém o UMAP num processador só, o que ele exige quando recebe um `random_state`, e avisa
disso se não pedirem.

- **Tamanhos também querem dizer pouco.** Uma mancha apertada pode ser um grupo espalhado espremido pelo
  método.
