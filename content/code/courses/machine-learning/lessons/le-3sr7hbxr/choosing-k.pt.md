O k-means acha tantos grupos quantos mandarem, e acha doze em dados que têm dois. O número tem de vir de
outro lugar, e duas medidas ajudam.

- A **inércia** sempre cai quando *k* sobe: mais centros ficam sempre mais perto das linhas. O que importa é
  onde ela para de cair rápido. Essa dobra é o **cotovelo**.
- A **silhueta** pergunta a cada linha quanto ela está mais perto do próprio grupo do que do outro mais
  próximo, numa escala de −1 a 1, e tira a média. Perto de 1, os grupos são apertados e separados; perto
  de 0, as linhas ficam entre grupos.

Salve isto como `choose_k.py`:

```python
# choose_k.py
import pandas as pd
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
from sklearn.preprocessing import StandardScaler

baskets = pd.read_csv("data/baskets.csv")
scaled = StandardScaler().fit_transform(baskets.drop(columns="customer_id"))
print(" k   inertia   silhouette")
for k in range(2, 9):
    kmeans = KMeans(n_clusters=k, n_init=10, random_state=0).fit(scaled)
    print(f"{k:2} {kmeans.inertia_:9,.0f} {silhouette_score(scaled, kmeans.labels_):12.3f}")
```

**As duas dizem quatro, e é raro ser tão claro assim.** A inércia cai 2.415 de dois para três, 1.632 de
três para quatro, e depois 119: depois de quatro, cada centro novo só divide um grupo que já estava junto.
A silhueta tem pico em quatro, 0,589, e cai dos dois lados.

Dados reais raramente são tão arrumados. O cotovelo muitas vezes é uma curva suave sem canto, e a silhueta
pode ter pico em dois, porque dividir uma população em duas metades é sempre razoavelmente limpo. Aí o
número vem do uso: a equipe de marketing consegue escrever quatro newsletters, não onze. **Um k sobre o qual o negócio não consegue agir está errado, diga o que disser a silhueta**, e entre dois valores que as medidas
não separam, o menor é mais fácil de explicar e de manter.
