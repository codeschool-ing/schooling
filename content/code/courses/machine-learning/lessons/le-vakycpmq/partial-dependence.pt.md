A importância diz quanto uma coluna importa, não como. A **dependência parcial** responde *como*: ponha a
coluna num valor só em toda linha, peça ao modelo as chances, tire a média, e repita numa faixa de valores. O
resultado é a chance média do modelo como função daquela coluna, com todo o resto como está. O scikit-learn
tem `partial_dependence`, e aqui ela está escrita por extenso, porque são quatro linhas e as quatro linhas
são a definição. Salve isto como `pdp.py`:

```python
# pdp.py
from sklearn.ensemble import HistGradientBoostingClassifier

from feira import CATEGORICAL, NUMERIC, by_time, load_churn

features = NUMERIC + CATEGORICAL
train, test = by_time(load_churn())
model = HistGradientBoostingClassifier(categorical_features="from_dtype", random_state=0)
model.fit(train[features], train["churned"])

for column, values in [("rating_90d", [3, 3.4, 3.6, 3.8, 4, 4.5, 5]),
                       ("skips_90d", [0, 1, 2, 3, 4, 5]),
                       ("days_since_login", [0, 7, 14, 21, 28, 40])]:
    average = []
    for value in values:
        rows = test[features].copy()
        rows[column] = value
        average.append(model.predict_proba(rows)[:, 1].mean())
    print(f"{column:17}" + "".join(f"{v:>7}" for v in values))
    print(f"{'average chance':17}" + "".join(f"{a:7.3f}" for a in average))
```

**Estas são as formas da aula 14, achadas de novo dentro do modelo de boosting.** A chance cai de 0,209 com
nota 3,4 para 0,110 com 3,6 e 0,054 com 3,8, o penhasco. Ela quase dobra entre dois pulos e três, o limiar.
Quase não se mexe em três semanas sem entrar, depois sobe, o salto. A aula 14 achou isso agrupando os dados
crus e entregou a uma regressão logística como marcas. As árvores tinham achado sozinhas, e é por isso que as
marcas não fizeram nada pelo boosting.

Essa é a coisa mais útil que a dependência parcial faz: **ela confere que o modelo aprendeu algo que uma
pessoa reconheceria.** Uma curva que subisse com a nota seria um modelo que aprendeu um erro, por melhor que
fosse a AUC dele.

Dois limites. Pôr a nota de todo assinante em 3 cria linhas que talvez nunca ocorram juntas, uma nota 3 ao
lado de quatro meses de entregas perfeitas, e a resposta do modelo ali é um palpite sobre um lugar onde ele
nunca esteve. E a média esconde diferenças: se assinantes jovens reagem a pulos e os mais velhos não, a curva
média mostra algo no meio que não descreve ninguém. Desenhar uma curva por assinante, a **expectativa
condicional individual**, mostra essa dispersão.
