Importance says how much a column matters, not how. **Partial dependence** answers *how*: set the column
to one value for every row, ask the model for its chances, average them, and repeat across a range of
values. The result is the model's average chance as a function of that one column, with everything else
left as it is. scikit-learn has `partial_dependence`, and here it is written out, because it is four lines
and the four lines are the definition. Save this as `pdp.py`:

```python
# pdp.py
from sklearn.ensemble import HistGradientBoostingClassifier

from feira import CATEGORICAL, NUMERIC, by_time, load_churn

features = NUMERIC + CATEGORICAL
train, test = by_time(load_churn())
model = HistGradientBoostingClassifier(categorical_features="from_dtype", random_state=0)
model.fit(train[features], train["churned"])

for column, values in [("rating_90d", [3, 3.4, 3.6, 3.8, 4, 4.5, 5]),
                       ("skips_90d", [0, 1, 2, 3, 4, 5]),
                       ("days_since_login", [0, 7, 14, 21, 28, 40])]:
    average = []
    for value in values:
        rows = test[features].copy()
        rows[column] = value
        average.append(model.predict_proba(rows)[:, 1].mean())
    print(f"{column:17}" + "".join(f"{v:>7}" for v in values))
    print(f"{'average chance':17}" + "".join(f"{a:7.3f}" for a in average))
```

**These are lesson 14's shapes, found again inside the boosted model.** The chance falls from 0.209 at a
rating of 3.4 to 0.110 at 3.6 and 0.054 at 3.8, the cliff. It nearly doubles between two skips and three,
the threshold. It barely moves for three weeks without logging in, then climbs, the jump. Lesson 14 found
these by grouping the raw data and handed them to a logistic regression as flags. The trees had found
them on their own, which is why the flags did nothing for boosting.

That is the most useful thing partial dependence does: **it checks that the model learned something a
person would recognise.** A curve that rose with the rating would be a model that had learned a mistake,
however good its AUC.

Two limits. Setting every subscriber's rating to 3 creates rows that may never occur together, a rating
of 3 beside four months of perfect deliveries, and the model's answer there is a guess about a place it
has never been. And the average hides differences: if young subscribers react to skips and older ones do
not, the average curve shows something in between that describes nobody. Drawing one curve per subscriber
instead, the **individual conditional expectation**, shows that spread.
