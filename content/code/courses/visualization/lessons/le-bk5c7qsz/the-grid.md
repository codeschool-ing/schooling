**Small multiples** are a set of small charts, all drawn the same way, each showing a different slice
of the data: one per region, one per product, one per year. Edward Tufte gave them their name in *The
Visual Display of Quantitative Information* (1983), and the idea is older than the name: the same frame
repeated, so that the only thing changing from panel to panel is the data.

Each region now has a panel to itself, so **every line can be read on its own**, with no crossings and
no legend: the panel's title names the region. Three design decisions make the grid work.

- **The same axes in every panel.** The same months along the bottom and the same scale up the side,
  0 to 9,000 orders. Because every panel matches, a reader who has understood one has understood them
  all, and the eye compares heights across panels directly.
- **The others in grey behind.** Each panel draws the other four regions as faint lines, so the strong
  line is seen in context: Northeast's panel shows it climbing past the grey line of South.
- **One row, in a sensible order.** Here the panels run from the region with the most orders in
  December 2025 to the one with the fewest. The fourth section of this lesson is about choosing that
  order.

## How small is small

Small enough that the whole set fits in one view, so that comparing two panels is a movement of the
eyes and not of the page. In practice:

- **up to about six panels in a row**, then wrap into a grid;
- **remove what repeats.** Axis labels on the left column and the bottom row only, tick labels sparse,
  one title per panel;
- **keep the panels the same size**, or the reader will read the larger one as more important.

Small multiples work for any chart type: lines, bars, histograms, scatterplots, maps. A grid of 12
small maps, one per month, shows how a pattern moves across a country better than any animation,
because the reader can look back.
