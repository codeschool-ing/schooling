When the number to show is a count, total orders, total stores, the choropleth's rule says not to
shade by it. A **proportional symbol map** shows it instead: a circle on each place, with **area
proportional to the count**.

Every state is now the same neutral grey, so the size of the state no longer competes with the data.
The circles carry the counts, and São Paulo's circle, bigger than its own square, says what the
counts map tried to say, without painting the whole state.

## The rules from lessons 2 and 6, again

- **Size by area, not radius.** A state with four times the orders gets twice the radius.
- **Area is read short.** Lesson 2's power law means the biggest circles look smaller, relative to
  the rest, than they are. Label the few that matter.
- **Draw the large ones first**, so the small ones on top stay visible, and use some transparency
  where circles overlap.

## Choropleth and symbols together

A map can carry both: shade the states by rate and put circles on them by count. The reader then sees
where Horta does well and where the volume is, which are different questions with different answers
here. It is a dense chart and it needs a clear legend for each layer, but for an audience used to
maps it is often the most useful single picture.

## Dots

A third option for counts is the **dot density map**: one small dot per, say, 100 orders, scattered
inside each state. It shows counts as visual density, which reads naturally, and it scales to fine
geography such as neighbourhoods. Its weakness is that the dots inside an area are placed at random,
so a reader may take the position of a dot as a real address.
