O laboratório inteiro é um script, o `nslab.sh`. Crie um diretório para ele na sua pasta pessoal da
máquina, abra um arquivo novo lá e cole o script nele. O botão de copiar no código abaixo entrega o
arquivo inteiro, sem as notas.

```sh
mkdir ~/nslab && cd ~/nslab
nano nslab.sh
```

## Estar numa máquina

O `sh` abre um shell numa das máquinas, como você, e o `root` abre um como root. O prompt diz onde
você está, e é assim que toda transcrição do curso está identificada: `ana@laptop:~$` é a usuária
`ana` no `laptop`, e `root@fw:~#` é o root no `fw`. As transcrições foram gravadas por uma usuária
chamada `ana`; o seu prompt mostra o seu próprio nome.

```
$ sudo bash nslab.sh sh laptop
ana@laptop:~$ hostname
laptop
ana@laptop:~$ probe db:5432 www:443
db:5432                open
www:443                open
ana@laptop:~$ curl -s https://www.example.com/
orders service: ok
ana@laptop:~$ exit
exit
$ sudo bash nslab.sh root fw
root@fw:~# nft list ruleset | wc -l
0
root@fw:~# exit
exit
```

O `laptop` chega ao banco de dados e à loja, porque o `fw` ainda não filtra nada, e o conjunto de
regras dele está vazio: nem uma linha. O `exit` traz você de volta ao seu próprio computador.

Cada máquina guarda os seus arquivos em `/lab`, no seu computador. A sua pasta pessoal no `laptop` é
`/lab/laptop/home/` seguido do seu nome, e o mesmo vale para todas as outras máquinas. Quando uma aula
copia um arquivo de uma máquina para outra, é ali que ela copia, com `sudo cp`:

```
$ ls -x /lab
admin  app  branch  branchpc  ca  db  desk  dns  fw  laptop  remote  sensor  www
$ sudo ls -A /lab/laptop/home/ana
.bash_history
.bash_logout
.bashrc
.profile
```

## Toda aula começa de um laboratório limpo

```sh
cd ~/nslab
sudo bash nslab.sh reset
```

O `reset` desmonta o laboratório e o monta de novo: toda regra, arquivo e processo que uma aula
deixou para trás desaparece. **Toda aula começa com ele**, e a primeira seção de cada uma diz o que
mais ela carrega. Quando o curso terminar, ou antes de apagar a máquina virtual,
`sudo bash nslab.sh down` remove o laboratório e tudo o que ele acrescentou ao computador.
