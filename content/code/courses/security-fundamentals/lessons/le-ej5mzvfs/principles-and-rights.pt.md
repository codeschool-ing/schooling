Ter uma base legal é necessário e não basta. O **artigo 6º** define princípios que todo tratamento precisa
respeitar, qualquer que seja a base, e o **artigo 18** dá às pessoas a quem os dados se referem, os
**titulares**, direitos que elas podem exercer contra a organização.

### Os princípios

| princípio | o que exige, na livraria |
|---|---|
| **finalidade** | tratar para propósitos legítimos, específicos e explícitos, informados à pessoa: "para entregar seu pedido" |
| **adequação** | o tratamento combina com a finalidade informada |
| **necessidade** | só o mínimo de dados necessário: nada de documento de identidade para vender um livro |
| **livre acesso** | as pessoas descobrem com facilidade o que é feito com os dados delas |
| **qualidade dos dados** | dados mantidos exatos e atualizados |
| **transparência** | informação clara sobre o tratamento e quem o faz |
| **segurança** | medidas técnicas e administrativas contra acessos não autorizados e acidentes |
| **prevenção** | medidas para evitar o dano antes que ele aconteça |
| **não discriminação** | nenhum tratamento para discriminação ilícita ou abusiva |
| **responsabilização e prestação de contas** | conseguir demonstrar, com evidência, que as regras são cumpridas |

Três desses dez são este curso com outros nomes. **Segurança** e **prevenção** são as aulas 4 a 12.
**Responsabilização** é a evidência da aula 13: a lei não exige só fazer a coisa certa, exige conseguir
provar. E **necessidade** é o controle de segurança mais barato que existe: dado que a loja nunca coletou
não vaza. Quando a aula 3 fez a loja apagar as cópias antigas dos documentos dos clientes, ela estava
evitando um risco e cumprindo esse princípio ao mesmo tempo.

### Os direitos

Um cliente pode pedir à loja, de graça:

| direito | o que a loja precisa conseguir fazer |
|---|---|
| **confirmação** e **acesso** | dizer se guarda dados dele, e fornecê-los |
| **correção** | corrigir dados incompletos, inexatos ou desatualizados |
| **anonimização, bloqueio ou eliminação** | de dados desnecessários, excessivos ou tratados em desconformidade com a lei |
| **portabilidade** | fornecer os dados para levá-los a outro fornecedor, conforme a ANPD regulamenta |
| **eliminação** dos dados tratados com consentimento | por exemplo, tirá-lo de vez da lista da newsletter |
| **informação sobre compartilhamento** | dizer com quem os dados foram compartilhados |
| **informação sobre o consentimento** | explicar que ele pode não consentir, e o que isso acarreta |
| **revogação do consentimento** | retirá-lo a qualquer momento |

O artigo 20 acrescenta o direito de pedir **revisão de decisões tomadas unicamente com base em tratamento
automatizado** que afetem os interesses da pessoa.

### O que os direitos querem dizer para o trabalho de segurança

Cada direito é um **processo** que alguém precisa tocar, e cada processo tem um lado de segurança. Antes de
entregar os dados a um cliente, a loja precisa ter certeza de que o pedido vem daquele cliente, ou o
direito de acesso vira um jeito de um estranho obter os dados de outra pessoa: a autenticação da aula 8,
aplicada a uma carta ou um e-mail. E eliminar dados a pedido quer dizer saber todo lugar onde eles moram,
inclusive nos backups, e é por isso que os prazos de retenção da aula 12 e o inventário da aula 16 também
importam aqui.
