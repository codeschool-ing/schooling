27001 ends with **Annex A**, a list of controls. 27002 contains the same controls, in the same order
and with the same numbers, each with a purpose and guidance on implementing it. The 2022 editions
hold **93 controls**, grouped into **four themes**:

| theme | number | examples |
|---|---|---|
| **organisational** (5.x) | 37 | information security policies, roles, asset inventory, access control, supplier security, incident management, business continuity |
| **people** (6.x) | 8 | screening, terms of employment, awareness and training, disciplinary process, remote working |
| **physical** (7.x) | 14 | secure areas, physical entry, equipment siting, clear desk, secure disposal |
| **technological** (8.x) | 34 | endpoint devices, privileged access, malware protection, backup, logging, networks, secure coding |

The four themes say something about where security work lives: 37 of the 93 controls are
organisational, about decisions and processes, and only 34 are technological. A large part of what a
certification audits is not configuration at all.

### New in 2022

The 2022 edition reorganised the 114 controls of 2013 into 93, merging many, and added **eleven new
controls**, which show what changed in a decade: threat intelligence, information security for the use
of cloud services, ICT readiness for business continuity, physical security monitoring, configuration
management, information deletion, data masking, data leakage prevention, monitoring activities, web
filtering and secure coding.

### Attributes

27002:2022 also tags every control with **attributes**, so the same 93 can be sorted different ways.
Two of them are already familiar: the **control type** (preventive, detective or corrective, lesson 4)
and the **information security property** it protects (confidentiality, integrity, availability, lesson
1). Another, **cybersecurity concepts**, uses the five functions of the NIST framework in lesson 15,
which is one of several bridges between the two families of standards.
