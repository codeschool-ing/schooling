---
title: A network is a graph of small steps
version: 1
---

The usual picture of backpropagation is an error signal sent back through the network, as if the
network had one mechanism for learning. **There is no such mechanism. There are only small
operations, each of which knows its own local derivative**, connected in a graph. Values flow
through it from the inputs to the loss, and gradients flow back along the same edges.

Here is the network the next section computes by hand: two inputs, two hidden ReLU units, one
output and lesson 2's squared error. Every number on it was printed by that section's program.

A node receives, from the edge on its right, the gradient of the loss with respect to its own
output. It multiplies that by its local derivative and sends the result left. Four kinds of node
cover every network in lessons 3 to 8:

| node | forward | what it sends back |
| --- | --- | --- |
| **sum** `a + b` | the sum | the arriving gradient, unchanged, to every term |
| **product** `w · h` | the product | to each factor, the arriving gradient times the *other* factor |
| **ReLU** | `max(0, z)` | the arriving gradient where `z` was positive, and 0 where it was not |
| **fork**, one value used twice | the same value on both edges | the **sum** of the gradients coming back along the edges |

Read the figure with the table beside it. The output is 1.75 against a target of 1, so the loss
sends back 1.5. The weight 1.5 from `h1` gets 1.5 times `h1`'s value, 1.0. The hidden unit `h2`
receives 1.5 from its edge, and its ReLU sends **0** back, because `z2` was -1. Every weight into
that unit therefore has a gradient of zero for this input: the unit took no part in the answer, so
nothing about it is to blame.

**The fork rule is the one people forget.** `x1` feeds both hidden units, so its gradient is the
sum of what comes back along two edges: 0.5 × 2.25 from `z1`, plus -0.5 × 0 from `z2`. Inputs are
never trained, so that number is useless here. But in a deeper network the input of this layer is
the output of the layer below, and the sum at the fork is exactly what is handed down to it.

The biases are left out of the drawing to keep it legible. A bias enters through a sum, so by the
first rule its gradient is whatever arrived at that sum: 1.5 for the output's, and 2.25 and 0 for
the hidden ones.
