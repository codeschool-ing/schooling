---
title: "A máscara causal: proibido olhar adiante"
version: 1
---

Um modelo que escreve texto é treinado para prever o próximo token a partir dos anteriores. Dê a esse
modelo a atenção da seção anterior e **cada posição consegue ver o token que deveria prever**, uma
coluna à sua direita. Ele aprende a copiar, a perda de treino cai, e o modelo não aprendeu
nada que possa usar: quando ele escreve, o próximo token ainda não existe.

A solução é proibir a olhada. **Antes da softmax, toda nota em que a chave vem depois da consulta vira
menos infinito.** A exponencial de menos infinito é exatamente 0, então esses pesos são 0 e cada linha
divide o seu peso entre os tokens até ela mesma, inclusive. Essa é a máscara causal, e ela é um
triângulo. Salve como `~/dl/causal.py`:

    },
    {
      "code": "def attend(q, k, v):\n    scores = q @ k.T / math.sqrt(d)\n    future = torch.triu(torch.ones(4, 4, dtype=torch.bool), diagonal=1)\n    weights = torch.softmax(scores.masked_fill(future, float(\"-inf\")), dim=-1)\n    return weights, weights @ v",

    },

**O primeiro token só pode ver a si mesmo, então o peso nele mesmo é 1,000**, e a sua saída é o seu
próprio valor. O segundo divide o peso entre dois tokens, 0,493 e 0,507. A quarta linha é exatamente a
linha sem máscara do `attention.py`, 0,203, 0,623, 0,102 e 0,071, porque o último token não tinha nada
depois dele para esconder. O `is_causal=True` do PyTorch dá o mesmo resultado até 1,2e-07.

A última linha testa a máscara. O quarto token foi trocado por inteiro, e **as três primeiras
saídas se moveram 0,000**, enquanto a quarta se moveu 0,535. Nada do que um token produz depende do que
vem depois dele, que é a propriedade de que o treino precisa.

**É assim também que um transformer treina numa sequência inteira de uma vez.** Com a máscara no lugar,
a posição 1 prevê o token 2, a posição 2 prevê o token 3, e assim por diante, tudo nos mesmos produtos de matrizes. Uma sequência de 1.000 tokens são 1.000 previsões de uma única passada para a frente. A
aula 14 mediu por que uma rede recorrente não consegue fazer isso, já que o passo 50 espera pelo passo
49. Escrever texto depois continua sendo um token de cada vez, cada token novo acrescentado e o modelo
rodado de novo, mas o treino é paralelo.

Um modelo que recebe a entrada inteira antes de responder não precisa de máscara. Um classificador que
