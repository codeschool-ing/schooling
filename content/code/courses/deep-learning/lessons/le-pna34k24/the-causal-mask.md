---
title: "The causal mask: no looking ahead"
version: 1
---

A model that writes text is trained to predict the next token from the ones before it. Give that model
the attention of the previous section and **every position can see the token it is supposed to
predict**, one column to its right. It learns to copy, the training loss falls, and the model
has learnt nothing it can use: when it writes, the next token does not exist yet.

The fix is to forbid the look. **Before the softmax, every score where the key comes later than the
query is set to minus infinity.** The exponential of minus infinity is exactly 0, so those weights are 0
and each row shares its weight among the tokens up to and including itself. That is the causal mask, and
it is a triangle. Save as `~/dl/causal.py`:

```schooling-example
{
  "language": "python",
  "file": "causal.py",
  "parts": [
    {
      "code": "\"\"\"causal: the same four tokens, each allowed to look only at itself and the ones before it.\"\"\"\nimport math\n\nimport torch\nimport torch.nn.functional as F\n\ntorch.set_printoptions(precision=3, sci_mode=False)\ntorch.manual_seed(0)\nd = 8\nq, k, v = torch.randn(4, d), torch.randn(4, d), torch.randn(4, d)",
      "note": "The same four tokens as `attention.py`: same seed, same width, so the weights can be compared row by row."
    },
    {
      "code": "def attend(q, k, v):\n    scores = q @ k.T / math.sqrt(d)\n    future = torch.triu(torch.ones(4, 4, dtype=torch.bool), diagonal=1)\n    weights = torch.softmax(scores.masked_fill(future, float(\"-inf\")), dim=-1)\n    return weights, weights @ v",
      "note": "`torch.triu(..., diagonal=1)` is `True` above the diagonal, where a token's key comes later than the query. Those scores become minus infinity before the softmax, and the exponential of minus infinity is exactly 0."
    },
    {
      "code": "weights, out = attend(q, k, v)\nprint(\"causal weights\\n\", weights)\nref = F.scaled_dot_product_attention(q[None], k[None], v[None], is_causal=True)[0]\nprint(\"largest difference from PyTorch's is_causal=True:\", f\"{(out - ref).abs().max().item():.1e}\")",
      "note": "The masked weights, and PyTorch's version of the same thing: `is_causal=True` builds the same triangle internally."
    },
    {
      "code": "q2, k2, v2 = q.clone(), k.clone(), v.clone()\nq2[3], k2[3], v2[3] = torch.randn(d), torch.randn(d), torch.randn(d)\n_, out2 = attend(q2, k2, v2)\nprint(\"change token 4, then how much each output moved:\", (out2 - out).abs().max(dim=1).values)",

    }
```

**The first token can only see itself, so its weight on itself is 1.000** and its output is its own
value. The second divides its weight between two tokens, 0.493 and 0.507. The fourth row is exactly the
unmasked row of `attention.py`, 0.203, 0.623, 0.102 and 0.071, because the last token had nothing after
it to hide. PyTorch's `is_causal=True` gives the same result to 1.2e-07.

The last line tests the mask. The fourth token was replaced entirely, and **the first three
outputs moved by 0.000**, while the fourth moved by 0.535. Nothing a token produces depends on what comes
after it, which is the property the training needs.

**This is also how a transformer trains on a whole sequence at once.** With the mask in place, position 1
predicts token 2, position 2 predicts token 3, and so on, all in the same matrix products: a sequence of
1,000 tokens is 1,000 predictions from one forward pass. Lesson 14 measured why a recurrent network
cannot do that, since step 50 waits for step 49. Writing text afterwards is still one token at a time,
each new token appended and the model run again, but the training is parallel.

A model that is given the whole input before it has to answer needs no mask. A classifier reading a
review, or the encoder of a translation model reading the sentence to translate, lets every token see
every other one, in both directions. BERT, from Google in 2018, is that kind of model. The model at the
end of this lesson is too: it answers after the last symbol, and its last position has nothing after it
to hide.
