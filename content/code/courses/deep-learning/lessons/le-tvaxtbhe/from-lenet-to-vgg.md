title: From LeNet to VGG, and why the filters got smaller
version: 1

An architecture is easy to read as a new invention each time, with a new name and a new diagram.
**Most of them changed one thing about the network before them**, and the change is what is worth
remembering. The convolution, the pooling and the dense head of lesson 11 were all there in 1998.

| year | network | what it changed |
| --- | --- | --- |
| 1998 | LeNet-5 | convolutions and pooling trained by backpropagation, reading handwritten digits for banks |
| 2012 | AlexNet | the same recipe much larger, on ImageNet's million photographs, trained on graphics cards, with ReLU and dropout |
| 2014 | VGG | only 3x3 filters, stacked two or three deep, and 16 or 19 layers |
| 2014 | GoogLeNet | filters of several sizes side by side, and 1x1 convolutions to cut the channels between them |
| 2015 | ResNet | the input of each block added back to its output, so 152 layers could be trained |
| 2017 | MobileNet | each convolution split into a cheap spatial filter and a 1x1 mixer, for phones |
| 2019 | EfficientNet | depth, width and image size grown together by one rule |

ImageNet, the competition behind most of that table, is 1,000 classes of photographs at around 224 by
224 pixels. The lab cannot download it, nor any trained weights, so **this lesson builds every
torchvision model with `weights=None`**: the architecture with random weights, which is all that
counting parameters and following shapes needs.

**VGG's idea is the one that lasted: a 5x5 filter can be replaced by two 3x3 filters in a row.** The
second filter sees a 3 by 3 patch of the first one's output, and each of those values saw a 3 by 3
patch of the input, so one value at the end depends on a 5 by 5 patch of the image.

The two 3x3 layers see the same 25 pixels as the 5x5 and cost 73,856 parameters against 102,464.
Three of them see 49 pixels, a 7 by 7 patch. **The stack is cheaper and it has a ReLU in the
middle**, so it can compute things one linear filter cannot, the argument lesson 1 made for layers.

The last lines show what all that cost. AlexNet held 61,100,840 parameters and VGG-16 more than twice
as many, and the place they sit is the surprise. Of VGG-16's 138,357,544, 123,642,856 sit
in the three dense layers at the end, and the thirteen convolutions that do the seeing hold
14,714,688. The first dense layer alone holds 102,764,544, because it reads the last maps laid out
as 25,088 numbers and joins every one of them to every unit after it. The networks after VGG shrank
that head, and ResNet replaced it with an average over each map and one small linear layer, as the
section on ResNet-18 shows.
