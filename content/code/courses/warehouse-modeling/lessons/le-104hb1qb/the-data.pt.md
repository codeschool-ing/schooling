A Ponto Final não existe, então as vendas dela são escritas por um programa: dois anos, de 1º de
janeiro de 2024 a 31 de dezembro de 2025, em sete lojas. O programa abaixo é tudo. **Você não precisa
lê-lo para acompanhar o curso**; as notas ao lado dizem o que cada parte sorteia, e o botão de copiar
entrega o programa sem elas. Salve-o como `~/wh/generate.py`.

#!/bin/sh
# Load the generated files in data/ into the shop's database, one table each,
# every table before the tables that point at it.
set -e

         customer_changes promotions orders order_lines payments stock_counts \
         events event_attendance; do
  psql -q -c "\copy $t FROM 'data/$t.csv' WITH (FORMAT csv, HEADER true)"
done
psql -q -c 'VACUUM ANALYZE'
