A phone installs an app only if it is signed. And the stores accept an update only if the same key signed the version before. {{sign}} So this lesson starts with what a signature proves, and with the one file you must never lose. {{key}} You will make an upload key with keytool, the tool that comes with Java. {{release}} Then a release build, and the first surprise: Expo's template signs it with the debug key unless told otherwise. {{signed}} Told otherwise, from the command line and without editing a generated file, both the APK and Google Play's bundle carry your key. The JavaScript inside is bytecode. {{eas}} Last, EAS Build: build profiles, credentials kept by Expo, and how an iOS app gets built when there is no Mac in the room.
