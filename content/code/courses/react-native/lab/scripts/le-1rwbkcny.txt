You write JavaScript. The phone shows a native button. What happens in between? {{threads}} This lesson opens the app up. There is a JavaScript engine inside it, running your code on a thread of its own. The screen belongs to another thread, the main one, and only it may touch a view. {{bridge}} For years the two talked through a bridge: messages, turned into JSON, sent one way and answered later. You will see what that cost. {{jsi}} Then what replaced it. JavaScript holding a reference to a C++ object and calling it directly. A renderer called Fabric. Modules that load when first used. {{boundary}} Then the honest part. What this course runs on an ordinary computer, and what needs a phone or a Mac. {{first}} And at the end, your first project.
