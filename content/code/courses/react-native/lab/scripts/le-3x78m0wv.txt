Today the planner becomes a project, and by the end of the lesson it is an Android app you could install. {{create}} It starts from Expo's template, with every version pinned, and with its rules and its data in files of their own. {{metro}} Then Metro, the bundler. You start the development server and ask it for the bundle yourself, the way a phone would. {{web}} The same project runs in a browser. And a small program reads the page back as a screen reader hears it. {{tests}} Then tests, which render the app with no screen at all and check the week's total. {{build}} Last, the native part. A Java kit, the Android SDK, and Gradle building a development build on your own computer. You open the package and see what is inside. And what is not.
