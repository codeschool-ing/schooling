Close the planner, open it again, and everything it knew is gone. {{kinds}} This lesson is about the places an app can keep things, and there are four, each for a different kind of thing. {{cache}} First the plan itself, saved by TanStack Query into AsyncStorage, so the app opens with yesterday's plan even when the server cannot be reached. {{sqlite}} Then SQLite, for a journal of every session this phone has marked done, and a query that adds it up per course. {{tests}} The journal's SQL is tested for real, by the SQLite that Node already carries, and its schema gets a second version without losing a row. {{web}} You will see it survive a reload in a browser. {{rest}} And last, MMKV for small values read at once, and the secure store for the one thing that must never sit in plain text.
