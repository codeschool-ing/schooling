There are two ways to start a React Native app, and they look the same on the first day. {{bare}} One is React Native on its own. You get an Android project and an Xcode project, and they are yours, to keep and to maintain, by hand. {{expo}} The other is Expo. A set of tools and libraries around the same React Native. Its own documentation now tells you to start here. {{go}} Expo Go runs your project on a phone without building anything. It is fast, and it has limits, and you will see where they are. {{prebuild}} Then the idea that matters most. With Expo, the native projects are generated, from one file. Change the file, generate again. {{plugins}} And when you need a native change, you write it as code that runs during generation. {{choice}} At the end, the honest comparison. What Expo gives you, and what it costs.
