One codebase, two platforms. Most of the time that is true. This lesson is about the rest of the time. {{os}} Your code can ask which platform it is on. Then it can choose a value for each one. {{files}} Or it can choose a whole file. Name it ending in dot ios, and Metro takes it for iPhones only. You will see each platform's bundle carry its own sentence and not the other's. {{differs}} Then what really differs. Shadows. The back button. The notch at the top and the bar at the bottom. {{test}} And one test, run four times, once as each platform. So a difference you wrote is a difference you checked.
