Until now the plan was a file inside the app. Today it moves to a server, and the app has to ask for it. {{server}} The server is twenty lines of Node. You will start it and talk to it with curl. {{query}} Asking is TanStack Query's job. It fetches, it caches, and it knows when what it has is too old. The app shows that it is loading, and says so plainly when the server is down. {{mutation}} Marking a session done becomes a request. The screen does not wait for it. It shows the change at once, and takes it back if the server refuses. {{offline}} And when the phone has no network, the request waits for it. {{live}} At the end, the web build against the real server. You will mark a session done in a browser and read the request in the server's log.
