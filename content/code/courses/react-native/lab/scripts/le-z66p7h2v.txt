A phone redraws its screen sixty times a second, often more. Miss one of those frames and a moving thing visibly jumps. {{budget}} This lesson starts with that budget: about sixteen milliseconds a frame, and the JavaScript thread is busy with other things. {{animated}} So an animation should not depend on it. The planner's week bar grows when a session is done, and the native driver runs that on the UI thread. {{frames}} Then you measure it. A small program presses the button in a browser and reads the bar's width every fifty milliseconds. {{reduced}} Some people ask their phone for less motion.
