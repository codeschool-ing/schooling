A list of three courses is easy. A list of a thousand sessions is where apps start to stutter. {{map}} You will put a thousand rows in a ScrollView and count what it creates. All of them. {{flat}} Then the same thousand in a FlatList. Ten. The rest are created as they scroll into view, and destroyed as they leave. {{keys}} Then keys. Remove one row from a list keyed by position, and watch another row inherit its neighbour's state. Keyed by id, nothing moves. {{sections}} Sessions grouped by day, with SectionList. {{perf}} And the handful of settings that decide whether a long list scrolls smoothly.
