Some bugs live only in the build your users have, and never in the one you are running. {{release}} This lesson starts with what changes between the two: the same app, exported both ways, compared byte for byte. {{env}} One of the differences is a value fixed at build time, which is the commonest bug of this kind. {{boundary}} Then a screen that throws gets a way out instead of a blank app. {{maps}} A server sends a plan in a shape the app does not expect, and the release build crashes in a minified line. Its source map leads back to the exact line of TypeScript. {{door}} The fix belongs at the door, where the data comes in. {{tools}} And last, the tools for looking at a running app: logs, and React Native DevTools.
