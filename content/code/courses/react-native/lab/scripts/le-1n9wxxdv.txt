There is no CSS file in a React Native app. Styles are JavaScript objects, attached to each element. {{sheet}} That sounds like a loss. You will see what it buys: no cascade to fight, no selector that reaches somewhere you did not expect. {{flex}} Layout is Flexbox, and only Flexbox. With two differences from the web that catch everybody. A column by default. And flex, a single number, means grow. {{bar}} The planner gets a bar for the week, built from two boxes and two numbers. A program measures it in the browser. {{units}} Then sizes. No pixels and no rems, but points that are the same on every phone. {{dark}} And dark mode, which is a question the phone answers and your code reads.
