## Ageing

**Moderate.** pandas broke its own API within living memory and NumPy 2 changed types under people. The concepts hold; the exact call in a screen recording may not.

## Flags

**1 ·** **The notebook is a second environment, and the course argues with it in its own second lesson.** *"Cells, execution order, and the notebook that only works out of order"* is a lesson about the tool's central defect, and the last lesson is *"From notebook to script"*. So the course cannot be taught in a plain editor without losing its subject, and cannot be taught only in a notebook without contradicting itself. **Whatever sandbox serves this course has to be a notebook**, which is a heavier thing to build than a shell.

**2 ·** **Seventy per cent blocked is the sweep's record**, and it beats `design-patterns` (25%) and `sql-databases` (60%). There is no degraded version of "run this and read the shape of the error" — this is the course that most conclusively cannot be published against the graders that exist.

**3 ·** **It sits between the catalogue's two hubs and inherits from one of them.** `python` has nine dependents and this is one of them; `machine-learning` is this course's only dependent, and `deep-learning` is behind that. A four-course chain in one track, each 70–90 hours: `python` → `python-data` → `machine-learning` → `deep-learning`. **A gap anywhere in it strands 320 hours.**
