## Why this is happening

An audit of the 39 written courses found 33 that hand the student something they never receive. The brief those courses were written from pointed at `networks`' `lab.sh` as the model and never said the student does not get it. The symptoms, in the order they were found:
- **A setup step that runs the author's script:** `sudo bash lab.sh up`, "copy the lab folder", "the lab script beside the course".
- **A command the lab installs under a plain name**, with its source never shown (`guard`, `vcrypt`, `toylm`, `pl`, `labgen`).
- **An example project the lessons use and never build:** `shop`, `shelf`, `loanbook`, `shipquote`.
- **Data the student never receives:** a database, a set of CSVs, a directory of documents.
- **A reference to the capture script's header**, as if the student could read it.
- **A setup lesson with only one path, or none recommended, or no section on failure.**

`validate-content` now refuses the first kind and anything naming `lab.sh`, `captures.sh` or a path under the course's own `lab/`. It cannot see the other kinds. You find those by reading.
